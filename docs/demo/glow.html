文字辉光 / 流光 · 四种做法

同一个句子的四种处理：静态外发光、呼吸发光、扫光带、逐字波浪。

A · 静态辉光

text-shadow 两层：近处实、远处虚。文字自己在发光，颜色不变。

字在发光
字在发光

B · 呼吸辉光

辉光强度随时间起伏，像字在轻轻吐息。最接近现在的光标质感。

字在呼吸
字在呼吸

C · 扫光带

background-clip: text + 移动渐变，一道白光扫过字面。品牌字标用的就是这一类。

光扫过字面
光扫过字面

D · 逐字波浪

每个字按顺序亮起又落下，光沿文字传播；需要把字拆成 span。

D 的逐字波浪依赖逐字 span，只能用在我们自己的元素上（品牌字标、设置页、发送转场的文字副本），不能直接套在宿主消息正文上。

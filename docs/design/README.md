## 一页速览

### 目标

在不改任何业务逻辑的前提下，给客户端加五处动效：

```
左上角 logo        鲜红鲸鱼 + 深→浅→深字标 + 流光扫过
输入框边框         一圈缓慢流动的光，聚焦加速、流式脉动
打字机光标         流式输出时呼吸/渐变，不再是生硬闪烁
按钮按压           输入区按钮统一手感，发送成功有一次闪光
新会话             首屏入场动画（不做按钮本体，见 04d）
```

### 三层架构

```
Tier 1 · Slot 占据        ★★★★★  官方 API，升级安全
Tier 2 · CSS on data-*    ★★★★☆  钩子稳定，纯样式
Tier 3 · 不写             ✗      hash 类名 / 本地化 aria / DOM 重排
```

### 品牌预设

插件的品牌区与**全部效果配色**由配置项 `brand` 决定，切换只改变量、不改包：

| 预设 | 品牌图形 | 主色 |
| --- | --- | --- |
| `ratel`（默认） | 蜜獾标识 + "Ratel" 字标 | `#2563EB`（仓库 `DESIGN.md` 的 `colorPrimary`） |
| `deepseek` | 鲸鱼 + "deepseek" 字标 + HARNESS 徽标 | `#FF3B30` |

包名固定为 `dsh-lumina`，不带品牌——**包名是能力，品牌是配置**（[01 §5](01-定位与命名.md)）。

### 关键数字（全部实测）

| 项 | 值 |
| --- | --- |
| 客户端已声明 slot | **89 个**（single / list / keyed / chain） |
| 稳定 `data-*` 语义钩子 | **369 个** |
| 运行时依赖 | **0**（不引入 gsap / three / framer-motion） |
| 参考库规模 | reactbits 免费站 217 个组件（WebGL 占 86 个，故只做设计参考） |
| 分期 | P0 品牌 → P1 输入框+光标 → P2 按压+首屏 → P3 预设 |

## 三条硬约束（违反即失败）

1. **不改 `app.asar`。** 它被代码签名逐字节封印，改一字节即破签、macOS 拒绝启动。所有实现必须在插件层完成。详见 [02](02-平台约束（执行前必读）.md)。
2. **不用 hash 类名做选择器。** 实际类名形如 `_3WPZCG_brandName`，每次构建都变。只用 `data-*` 与官方 slot。
3. **不碰业务逻辑。** 动效不承载信息；关掉后功能与含义完全不变。不监听模型输出、不改请求、不写业务状态。

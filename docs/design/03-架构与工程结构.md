# 03 · 架构与工程结构

> 前置阅读：[02-平台约束](02-平台约束（执行前必读）.md)

## 3.1 三层架构

```
Tier 1 · Slot 占据        ★★★★★  官方 API，升级安全
   brand.mark / brand.name / hero.mark / settings.section / input.overlay
   → React 组件，内联 SVG，可承载任意动画

Tier 2 · CSS on data-*    ★★★★☆  钩子稳定，纯样式
   [data-composer-card] / [data-lexical-cursor] / [data-streaming]
   → 单条 <style> 注入，全部选择器基于 data-*

Tier 3 · 不写             ✗      拒绝
   hash 类名 / 本地化 aria-label / DOM 重排 / 高频轮询
```

**分层的目的**：让每个效果的可信度是明确的。Tier 1 出问题基本不可能；Tier 2 出问题的概率与 DSH 改 `data-*` 钩子的概率相同，且失效时静默降级——不会把界面弄坏。

## 3.2 打包决策：单包，只服务 DSH

**`dsh-lumina` 是唯一的包。** 不拆"引擎 + 品牌包"，不做跨产品复用设计。

Lumina 的动效绑死在 DSH 的 `data-*` 钩子与 Cordis slot 上，挪到任何其它界面都不匹配，所以复用是伪需求。品牌差异（Ratel / DeepSeek）用**配置**表达，不用拆包。

结论见 [01 §5](01-定位与命名.md)。

## 3.3 包内模块划分

| 选项 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| 5 个独立包 | 隔离彻底 | 用户要装 5 次；slot 竞争更复杂 | ✗ |
| 单一包，效果内联 | 装一次到位 | 一个效果崩全崩 | ✗ |
| **单包 + 效果独立模块** | 装一次；单效果失败可隔离 | 略复杂 | ✓ |

关键设计：**每个效果模块自己 try/catch，互不影响。** 边框流光的选择器失效，不该影响品牌 logo 的渲染。

## 3.8 lib/client.js 骨架

```js
window.__ModuleLoader__.load({
  id: "dsh-lumina",
  factory: (require) => {
    var module = { exports: {} };
    var exports = module.exports;
    Object.defineProperty(exports, Symbol.toStringTag, { value: "Module" });

    // ---------- config ----------
    var KEY = "dsh-lumina/settings/v1";
    var DEFAULTS = {
      version: 1,
      master: true,
      brand: "ratel",                 // 品牌预设：ratel | deepseek
      effects: { brand: true, composerGlow: true, caret: true, press: true, hero: true },
      intensity: "normal",
      reduceMotionFollow: true,
    };

    function readConfig() {
      try {
        var raw = localStorage.getItem(KEY);
        if (!raw) return { ...DEFAULTS };
        var v = JSON.parse(raw);
        if (!v || v.version !== 1) return { ...DEFAULTS };
        return {
          ...DEFAULTS,
          ...v,
          effects: { ...DEFAULTS.effects, ...(v.effects || {}) },
        };
      } catch (e) {
        return { ...DEFAULTS };
      }
    }

    var config = readConfig();

    // ---------- reduced motion ----------
    var mq = window.matchMedia("(prefers-reduced-motion: reduce)");
    function reduced() {
      return config.reduceMotionFollow && mq.matches;
    }

    // ---------- style injection ----------
    var styleEl = null;
    function installStyles(css) {
      if (styleEl) styleEl.remove();
      styleEl = document.createElement("style");
      styleEl.dataset.plugin = "dsh-lumina";
      styleEl.textContent = css;
      document.head.append(styleEl);
    }
    function removeStyles() {
      if (styleEl) { styleEl.remove(); styleEl = null; }
    }

    // ---------- effect registry (failure isolated) ----------
    var cleanups = [];
    function runEffect(name, fn) {
      if (!config.master || !config.effects[name]) return;
      try {
        var off = fn();
        if (typeof off === "function") cleanups.push(off);
      } catch (e) {
        console.warn("[dsh-lumina] effect failed: " + name, e);
      }
    }

    // ---------- effects (filled in by 04a–04d) ----------
    function apply(ctx) {
      runEffect("brand", function () { /* 04a */ });
      runEffect("composerGlow", function () { /* 04b */ });
      runEffect("caret", function () { /* 04c */ });
      runEffect("press", function () { /* 04d */ });
      runEffect("hero", function () { /* 04d */ });
    }

    exports.apply = apply;
    exports.inject = ["slots"];
    return module.exports;   // ← 关键，见 02 §2.8
  }
});
```

## 3.9 配置存储

`localStorage["dsh-lumina/settings/v1"]`：

```json
{
  "version": 1,
  "master": true,
  "brand": "ratel",
  "effects": {
    "brand": true,
    "composerGlow": true,
    "caret": true,
    "press": true,
    "hero": true
  },
  "intensity": "normal",
  "reduceMotionFollow": true
}
```

字段语义：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `version` | `1` | schema 版本；不匹配则回落默认值，不做静默迁移 |
| `master` | boolean | 总开关 |
| `brand` | `"ratel"` \| `"deepseek"` | **品牌预设**。决定品牌区图形与全部效果的品牌色（见 [04 §4.5](04-动效规格总览.md)）。默认 `"ratel"` |
| `effects.*` | boolean | 逐效果开关 |
| `intensity` | `subtle` \| `normal` \| `vivid` | 映射到时长/幅度倍率（0.6 / 1.0 / 1.4） |
| `reduceMotionFollow` | boolean | 跟随系统减少动态。**默认 true，不提供关闭入口** |

**校验原则**：非法值一律回落到默认，不抛错、不半应用。参照 `dsh-brand-studio` 的做法——读取时保守校验，写入时整体替换。

## 3.10 设置面板

占据 `settings.section`（list slot），`id: "dsh-lumina"`，`order` 取较大值排在后面。

面板内容：

- 总开关
- 五个效果的独立开关 + 一句话说明
- 强度档位（subtle / normal / vivid）
- 实时预览区（小号 logo + 一个假输入框，让用户不离开面板就能看到效果）
- 「恢复默认」

面板本身是官方扩展点，**风险为零**。

## 3.11 三层降级

| 层级 | 手段 | 生效范围 | 用途 |
| --- | --- | --- | --- |
| L1 | 设置面板逐效果开关 | 单个效果 | 日常调节 |
| L2 | `document.documentElement.dataset.lumina = 'off'` | 全部 Tier 2 | 紧急止血（Console 一句） |
| L3 | `dsh plugin --profile web remove dsh-lumina` + 重启 | 全部 | 彻底移除 |

L2 的 CSS 兜底：

```css
[data-lumina="off"] * {
  animation-duration: 0s !important;
  animation-iteration-count: 1 !important;
  transition-duration: 0s !important;
}
```

## 3.12 性能与无障碍约束（硬性）

| 项 | 约束 |
| --- | --- |
| 合成层 | 只动 `transform` / `opacity`；不碰 `width`/`height`/`top`/`left` |
| 常驻动画上限 | ≤2 条（边框 + 光标），其余为一次性或交互触发 |
| 避免重排 | 装饰层一律 `position: absolute` + `pointer-events: none` |
| `will-change` | 只在交互期间临时加，不常驻 |
| 帧预算 | 60fps 下每帧 ≤4ms；以 DevTools Performance 实测为准 |
| 减少动态 | 每个效果都必须实现 `prefers-reduced-motion` 关闭分支 |
| 对比度 | 动效不得降低文字对比度；流光扫过处仍需 ≥4.5:1 |
| 闪烁频率 | 不得落在 3–50Hz（光敏性癫痫） |
| 语义 | 动效不承载信息；关掉后功能与含义不变 |

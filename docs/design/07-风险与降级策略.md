## 7.2 三层降级

| 层级 | 手段 | 生效范围 | 适用场景 |
| --- | --- | --- | --- |
| **L1** | 设置面板逐效果开关 | 单个效果 | 日常调节、不喜欢某个效果 |
| **L2** | `document.documentElement.dataset.lumina = 'off'` | 全部 Tier 2 | 紧急止血（Console 一句，无需重启） |
| **L3** | `dsh plugin --profile web remove dsh-lumina` + 重启客户端 | 全部 | 彻底移除 |

### L2 的 CSS 兜底

```css
[data-lumina="off"] *,
[data-lumina="off"] *::before,
[data-lumina="off"] *::after {
  animation-duration: 0s !important;
  animation-iteration-count: 1 !important;
  transition-duration: 0s !important;
}
```

注意要覆盖 `::before` / `::after`，否则边框流光（伪元素）不会停。

### 降级设计原则

- **降级不能留空壳。** 效果关掉后，控件必须回到官方样子，不能留一圈透明的占位。
- **降级不能报错。** 关掉后 Console 不应出现新告警。
- **降级不影响功能。** 关掉后输入、发送、新建会话必须完全正常。

## 7.3 升级适配 playbook

DSH 升级后，Tier 2 可能静默失效。按以下顺序排查，**10 分钟内**能定位。

### 第一步：确认插件还活着

```js
window.__DSH_BOOT__.entries.filter(e => e.id === 'dsh-lumina')
```

为空 → 是装载问题（[02 §2.8](02-平台约束（执行前必读）.md) 四条），不是钩子问题。

### 第二步：检查依赖钩子是否还在

```js
const hooks = [
  'data-composer-card',
  'data-composer-input',
  'data-lexical-cursor',
  'data-streaming',
];
hooks.forEach(h => {
  const n = document.querySelectorAll('[' + h + ']').length;
  console.log(h, n > 0 ? 'OK (' + n + ')' : 'MISSING');
});
```

输出 `MISSING` 的那条，就是失效的钩子。

### 第三步：找新钩子

```js
// 列出当前页面所有 data-* 属性及出现次数，找语义相近的替代
const counts = {};
document.querySelectorAll('*').forEach(el => {
  for (const a of el.attributes) {
    if (a.name.startsWith('data-')) counts[a.name] = (counts[a.name] || 0) + 1;
  }
});
console.table(
  Object.entries(counts)
    .sort((a, b) => b[1] - a[1])
    .slice(0, 60)
);
```

### 第四步：更新 + 重装 + 重启

改选择器 → 重装（remove / 清 node_modules / add）→ 重启客户端 → 重跑 §6.4 证据。

### 维护建议

把这套检查写成一个开发模式下的诊断按钮，放在设置面板里（"检查钩子状态"），升级后用户自己就能看出哪个效果失效。

## 7.4 阻断级问题清单

以下问题一旦出现，**必须立刻回滚**，不允许"带着已知阻断问题发布"：

| 问题 | 为什么阻断 |
| --- | --- |
| 输入框无法聚焦 / 无法输入 | 核心功能失效 |
| 装饰层挡住点击 | 核心功能失效 |
| 光标不可见或位置错乱 | 影响输入体验 |
| 发送按钮失效 | 核心功能失效 |
| 插件导致控制台持续报错 | 污染排障面 |
| 卸载后残留样式/元素 | 用户无法回到官方状态 |
| 品牌区出现双重字标 | 视觉崩坏 |
| 流光导致文字不可读 | 无障碍问题 |

## 7.5 回滚步骤

```sh
DSH="/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh"

# 1. 移除
"$DSH" plugin --profile web remove dsh-lumina

# 2. 清理残留（可选，确认彻底）
rm -rf ~/.dsh/profiles/web/node_modules/dsh-lumina

# 3. 确认 bundles 里已无
python3 -c "import json;d=json.load(open('$HOME/.dsh/profiles/web/package.json'));print(d['dsh']['profile']['bundles'])"

# 4. 重启客户端
```

回滚后必须验证：**客户端视觉与未安装前一致**，且 `document.querySelectorAll('[class*=lumina],[data-lumina]').length === 0`。

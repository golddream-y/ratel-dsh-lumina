稳定性星级的含义：

- ★★★★★ 官方 slot，只要遵守注册契约就不会因版本升级失效

## 4.3 通用实现规则

所有效果共同遵守（重复是有意为之，方便单独派工时不必回看总览）：

### 4.3.1 动效参数化

时长与幅度必须从配置读取，不写死：

```js
var K = config.intensity === 'subtle' ? 0.6
      : config.intensity === 'vivid'  ? 1.4
      : 1.0;
// 例：基准 3.6s → 注入时用 (3.6 / K)
```

CSS 侧通过注入时字符串替换或 CSS 变量传参：

```css
:root { --lumina-speed: 1; }
```

### 4.3.2 减少动态必须覆盖

```css
@media (prefers-reduced-motion: reduce) {
  /* 每个效果自己写这一段，不能省 */
}
```

**不允许**把 `reduceMotionFollow` 做成可关闭的选项。这是无障碍底线。

### 4.3.3 作用域隔离

所有注入的类名/属性带 `lumina` 前缀，避免与官方或其它插件冲突：

```css
/* 类名 */
.lumina-shine { }
/* 数据属性 */
[data-lumina-sent] { }
/* 样式标签标记 */
style[data-plugin="dsh-lumina"]
```

### 4.3.4 失败隔离

每个效果在自己的 `try/catch` 里初始化：

```js
runEffect("composerGlow", function () {
  try { /* ... */ } catch (e) {
    console.warn("[dsh-lumina] composerGlow failed", e);
  }
});
```

一个效果崩了，其余必须照常工作。

## 4.4 品牌预设

`brand` 配置项决定两件事：**品牌区画什么** + **全部效果用什么色**。

| 预设 | 品牌图形 | 主色 | 来源 |
| --- | --- | --- | --- |
| `ratel`（默认） | 蜜獾标识 + "Ratel" 字标 | `#2563EB` | 仓库 `DESIGN.md` 的 `colorPrimary` |
| `deepseek` | 鲸鱼 + "deepseek" 字标 + HARNESS 徽标 | `#FF3B30` | 已有资产 `assets/deepseek-harness-logo-v2.svg` |

### 实现方式

预设 = 一组 CSS 变量 + 一份品牌 SVG。切换时只换变量与图形，**动效机制（流光、呼吸、边框旋转）完全复用**。

```css
:root {
  --lumina-brand: #2563EB;
  --lumina-brand-soft: #93B4F8;
  --lumina-brand-deep: #1E3A8A;
  --lumina-brand-rgb: 37, 99, 235;
}

[data-lumina-brand="deepseek"] {
  --lumina-brand: #FF3B30;
  --lumina-brand-soft: #FFB3A8;
  --lumina-brand-deep: #8C1D12;
  --lumina-brand-rgb: 255, 59, 48;
}
```

生效方式：在 `<html>` 上写 `data-lumina-brand="<预设>"`。

### 对已有实现的影响（重要）

若品牌预设化在效果实现**之后**才引入，必须回头把 04b / 04c / 04d 里的硬编码色值改成变量，否则切品牌后只有品牌区变色、其余仍是红色。

**本文件集的 04b / 04c / 04d 已按变量写法给出**，可直接照抄。

### 待补

Ratel 的蜜獾图形**尚未设计**（仓库内无任何 Ratel logo 资产）。在它完成前，`brand: "ratel"` 可先用文字字标 "Ratel" + 品牌色块占位。见 [07 风险表](07-风险与降级策略.md) R15。

## 4.5 设计变量

新增效果时复用这张表，保证质感统一。

### 颜色（由品牌预设提供，**不得在效果里硬编码**）

所有效果消费 CSS 变量，变量值由当前 `brand` 预设注入。这是品牌可切换的前提——硬编码色值会让切到 Ratel 时边框还是红的。

| 语义 | Ratel 预设 | DeepSeek 预设 | 用途 |
| --- | --- | --- | --- |
| `--lumina-brand` | `#2563EB` | `#FF3B30` | 图标主色、边框高光、光标、闪光 |
| `--lumina-brand-soft` | `#93B4F8` | `#FFB3A8` | 流光/渐变浅端 |
| `--lumina-brand-deep` | `#1E3A8A` | `#8C1D12` | 字标肩部 |
| `--lumina-brand-rgb` | `37, 99, 235` | `255, 59, 48` | 供 `rgba(var(...), α)` 使用 |
| `--lumina-edge` | `#12100F` | `#12100F` | 字标两端（浅色主题） |
| `--lumina-edge-dark` | `#F4F1F0` | `#F4F1F0` | 字标两端（深色主题） |
| `--lumina-hi` | `#FFFFFF` | `#FFFFFF` | 流光高光带 |

> Ratel 主色 `#2563EB` 取自仓库 `DESIGN.md` 的 `colorPrimary`（真源，不在此复制决策依据）。

### 时长

| 用途 | 基准 | subtle | vivid |
| --- | --- | --- | --- |
| 品牌流光扫过 | 3.6s | 6.0s | 2.6s |
| 边框旋转一周 | 6.0s | 9.0s | 4.2s |
| 光标呼吸 | 1.15s | 1.6s | 0.85s |
| 按钮按压 | 140ms | 180ms | 110ms |
| 首屏入场 | 320ms | 420ms | 240ms |
| 发送闪光 | 520ms | 620ms | 420ms |

### 缓动

| 名称 | 曲线 | 用途 |
| --- | --- | --- |
| 入场 | `cubic-bezier(.22,1,.36,1)` | 首屏、面板出现 |
| 回弹 | `cubic-bezier(.34,1.56,.64,1)` | 按钮按压 |
| 匀速 | `linear` | 边框旋转、流光扫过 |
| 呼吸 | `ease-in-out` | 光标透明度 |
| 出场 | `ease-out` | 发送闪光 |

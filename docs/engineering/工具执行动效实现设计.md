# 工具执行动效实现设计

日期：2026-10-29。状态：首版已实现并完成受控构建验证，原生客户端验收待确认。视觉与交互要求以[工具执行动效设计](../product/工具执行动效设计.md)为准。

## 现有宿主事实

以下来自本机 DSH 0.2.1-rc.3 安装包的只读检查，不代表插件运行时已经完成 DOM 验证。

| 对象 | 已确认的标记与行为 | 使用限制 |
| --- | --- | --- |
| 通用 ToolRow | 根元素含 `data-tool`、`data-variant`、`data-state`；状态为 `preparing / running / ok / error / stopped` | `ask_user_question` 也使用此结构，必须排除；不能把任意 `data-state` 当成工具 |
| BashRow | 标题行含 `data-sample="bash"`、`data-variant="bash"`、`data-state`；可展开时带 `role="button"`、`aria-expanded`、`data-expandable` | 终端正文是标题行的兄弟节点，不在标题根内；现有事实没有稳定正文专用属性 |
| 通用展开行 | 调用宿主 DisclosureRow，正文按 open 条件惰性挂载 | 内层触发器、正文钩子和关闭卸载时点仍需实际 DOM 核查 |
| 工具状态 | 源码由宿主生成准备、执行、成功、失败、停止状态 | 不通过命令文字、图标颜色或无障碍提示翻译来猜状态 |
| 过程分组 | Chat 提供 `data-process-activity` 及独立分组标题 | 首轮不装饰分组，避免与子工具重复 |

通用命令和推理行也有 `data-variant` 与 `data-state`，但不一定是工具。应限定当前聊天区及明确工具属性，不使用散布全局的 `[data-state="running"]`。不使用 CSS hash 类名，不 require 宿主 ui-tool 或 primitives 模块，不接管工具视图 slot。

## 适配与覆盖门槛

在 `adapter/targets.ts` 增加工具行、状态及展开目标查询，封装通用工具和 Bash 标题两类适配。候选结构仅为 `[data-tool][data-variant][data-state]` 与 `[data-sample="bash"][data-variant="bash"][data-state]`，还须核对当前聊天区、原生节点身份、真实可见范围与排除项。

实现前确认可靠的工具调用身份：优先原生聊天节点稳定键，并核查一个节点是否可能包含多次工具调用。只有 DOM 元素引用而没有稳定身份时，不能把重新挂载区分为新执行，应跳过出现和完成的一次性动效。订阅首次扫描只建立基线；切会话、加载历史和重新挂载不能触发“新工具”装饰。

提问、授权确认、嵌入会话及第三方自定义视图默认不覆盖。未知结构保留原样。适配信息写入兼容清单，并在原生客户端核对，不把安装包中的字符串命中当作效果接入成功。

## 效果实例与状态交接

计划在独立的 `effects/tool-motion.ts` 管理装饰实例，由现有 registry 及设置开关统一安装、卸载。实例记录身份、上次宿主状态、首次发现原因、局部动画句柄和可见性，不复制业务状态源、不发起事件流或额外会话绑定。

状态观察仅限已确认的属性和节点增删，使用 MutationObserver 合并处理；IntersectionObserver 管理持续柔光的可见额度。仅明确的 `preparing/running → ok` 产生完成收束，初见 `ok` 不补播。错误、停止或排除状态立即清理，原生提示立刻显示。重入 running 从当前装饰接续，取消旧完成动画；多个事件同批到达时直接使用最终状态。

约 200 ms 的启动等待只控制持续装饰，不能隐藏文字或延迟宿主结果。成功收束与正文显示并行。每个实例的暂停、取消与卸载应幂等；移除节点时释放观察、计时器和引用，不保留无限增长的历史完成集合。

## 绘制与展开

持续装饰改为图标槽位周围两层静态径向渐变，仅动画 transform / opacity；不画标题下划线、不动态模糊、不创建 SVG 路径、画布或设备。光晕中心从原生 DisclosureRow 的首个 leading 子元素或 Bash 标题的首个 leading 子元素测量，并验证槽位内存在 SVG、尺寸合理；原生图标不替换、不包裹、不变色。小范围柔光不能变成实心球或遮盖文字。

装饰层固定在图标中心，尺寸不超过 30 px，`aria-hidden`、`pointer-events:none`，不改根元素的业务宽高。定位通过标题与图标实际矩形、标题本地尺寸换算，支持缩放。布局读取仅发生在事件刷新，缺少图标或无有效槽位时跳过，不回退固定坐标。主题由 CSS 变量直接跟随。原生文字已有 TextShimmer，不叠加第二个文字扫光。

原生内容出现后可做短暂 opacity / transform 反馈，但不得把包含原生交互、选区或终端内容的区域长期变成截图。收起正文若即时卸载，直接保留原生卸载，不复制日志、不延迟状态、不阻断点击。只有核对到稳定正文和邻接布局钩子后，才评估有界 FLIP；先确认没有与宿主聊天位移动画及自动滚动重复工作。

## 调度、恢复与验证

遵守[动效性能架构](动效性能架构.md)，同屏最多两处持续装饰，其余保留原生反馈；零目标时不保留插件绘制任务。CSS 跟随全局暂停标记，失效几何只在事件中测量。不要为该功能新建设备、画布或每工具 rAF。减少动态时只保留原生静态呈现。

返回可见窗口只检查目标当前是否运行，续播有效装饰；不重播已结束状态。配置关闭、清理或节点销毁后迟到回调无效，恢复开关也不补播历史。新增配置字段兼容旧配置，旧字段和模式选择不被重置。

测试应验证：初见完成不播放、快速完成无闪烁、状态打断不排队、两处额度、离屏与恢复、关闭与卸载无残留；再用真实客户端验证选择、复制、链接、终端滚动、自动滚动与嵌套工具。性能比较固定同一日志负载与 1/3/8 个运行工具的场景，分别记录插件关闭和开启，不把脚本回调频率当作实际帧率。

原生客户端仍需确认：缩放与深浅背景的观感、滚动协调及工具树变化后的覆盖。首版不对历史或重挂载播放整卡入场，不做正文关闭和邻接布局动画。


## 首版接入约束（2026-10-29）

已从本机 rc.3 前端与工具模块确认：通用工具标题使用 `data-disclosure-header`，点击区为 `data-disclosure-row`，正文是标题的后继兄弟且关闭时立即卸载；Bash 标题自身带 `data-sample="bash"`，正文是其后继兄弟。工具调用外层含 `data-chat-flow-kind="tool-call"`、`data-chat-node-key`，聊天区含会话标识。

首版仅覆盖一个调用节点内只有一个已识别工具行的情况，允许 read/search/write/edit/code/bash 类型；排除提问、确认、未知类型和多根嵌套调用。标题按事件测量，尺寸变化由 ResizeObserver 刷新；只在当前可见且未折叠区域启动图标局部 CSS 柔光，最多两处持续播放，最多追踪 128 个运行或短暂反馈实例。预算集中于性能模块，不新增 GPU 或绘制循环。

首次挂载只建立基线，已完成历史不入场、不补播完成。新运行行的淡入由柔光启动表达；仅同一挂载期间明确的准备到运行切换可给标题一次轻反馈，不对身份不明的新 DOM 做整卡入场。展开正文仅在标题的原生展开属性由 false 变为 true 时淡入；收起完全保留原生卸载，不做高度或邻接布局动画。后续有更强实时调用信号时再扩大一次性入场范围。

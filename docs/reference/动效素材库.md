# 动效素材库

这里收集**只读参考**：看别人的效果、时序和代码组织，抄思路后按 Lumina 的约束重写。
**不把下列库作为运行时依赖引入**，也不复制受限制的源码进 `src/`。

## 收录原则

- 优先 MIT / ISC / Apache-2.0；
- GPL-3.0 只做视觉参考，不复制代码、不打包；
- GSAP 这类“免费但非 OSI”的库只参考时间线和参数；
- 复制粘贴组件库时先看 license，尤其是 Commons Clause；
- 我们的客户端 bundle 只允许 `react` / `react/jsx-runtime`，所有素材最终都要落到 CSS/keyframes 或自写 JS。

## anime.js

- 官网：<https://animejs.com/>
- 源码：<https://github.com/juliangarnier/anime>
- 协议：MIT
- 用途：stagger、timeline、spring/ease、逐字/逐 SVG 变换。
- 只抄：
  - 多元素错峰（stagger）的节奏；
  - 时间线串接（先位移、再辉光、再回落）；
  - 弹簧/回弹曲线参数；
  - SVG 路径绘制和 morph 的组织方式。
- **不引入**：当前 CSS keyframes 足够，避免给 client bundle 增加运行时。

## 本项目的效果映射

| 想要 | 参考 | Lumina 的实现方向 |
| --- | --- | --- |
| 震动 | Textillate / Animate.css `shake` | 自写 `translate/rotate` keyframes，逐字错峰 |
| 火焰 | CSS 多层 `text-shadow` + `flicker` | 自写 keyframes；不用库 |
| 辉光 | `ShinyText` / GSAP glow | 自写 `text-shadow` / `filter` 呼吸 |
| 故障 | React Bits `GlitchText` | 两份错位文本 + `clip-path` |
| 逐字出现 | anime.js stagger | 自写 `animation-delay` 或 CSS 变量 |
| 打字脉冲 | 本项目 | 光标处柔光环 + 光标呼吸，不改写文本 |

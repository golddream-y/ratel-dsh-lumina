# 工具执行动效设计

日期：2026-10-29。状态：设计草案，附交互原型；尚未接入客户端。原型用于确认节奏和视觉，不是客户端还原度验收。

## 目标与范围

让工具从出现、执行到结束的变化更连贯，同时保持命令、日志和文件差异易读。动效只跟随宿主已有状态，不表示完成比例、不改变工具执行或展开行为。

首轮覆盖当前 DSH 的文件读取、搜索、文件修改等通用工具行，以及命令执行标题行。沿用原来的工具图标、名称、摘要、错误与退出码。提问、授权确认、子 Agent 卡片和第三方自定义工具视图暂不覆盖；未知结构保持原样。

## 视觉方向

使用与现有丝带、星河同源的冷暖混色。正在执行时，标题下沿出现一段局部光绸：细亮线外带柔光，内部两股光轻缓交错、局部亮度起伏。它不是从头到尾反复刷过的进度条，也不铺满整张卡片。保留工具图标，不增加另一颗光团，不给标题叠加第二层文字扫光。

首版光绸宽度取标题区域的约三至五成，上限 140 px、高约 6–8 px；细亮线不超过 1 px。只占标题下方的装饰区域，不跨过日志、链接或差异内容。上述为原型起始参数，需在真实行高和缩放比例下确认。品牌预设影响装饰，原生成功、失败和等待确认的语义颜色不跟随改色。

## 状态与节奏

| 时刻 | 表现 | 边界 |
| --- | --- | --- |
| 新工具出现 | 标题在约 180 ms 内淡入，最多向上归位 2 px | 仅本次可见的新增工具；打开旧会话和向上加载历史不重播 |
| 准备参数 | 保留原生准备提示，局部低亮柔光渐入 | 不提前表示已经执行；不让原来不可展开的行变得可展开 |
| 正在执行 | 光绸约 2.8 s 一次舒缓交错，运行期间连续变化 | 无百分比、无星点、无全卡呼吸；正文静止 |
| 成功完成 | 光绸在约 260 ms 内收短、变细并淡出，留下正常标题 | 不自加绿色对勾或改写状态；不自动展开或收起结果 |
| 失败、停止、待确认 | 约 120 ms 内撤去装饰，立即显露原生状态 | 不抖动、不闪红、不延迟交互；不把准备状态猜成待确认 |
| 极快完成 | 200 ms 内结束的不启动持续光绸，只保留一次轻淡入 | 避免亮一下立刻消失；结果立即可见 |

这些时长是视觉预算，不等待动画结束再显示执行结果。状态迅速连续变化时从当前画面收束，不排队播放过期阶段；同一帧出现并完成的工具直接呈现最终状态。

## 展开与收起

点击或键盘操作立即交给宿主。原箭头在已核实可定位时，用约 160 ms 转向；新显示的内容在约 180 ms 内淡入，最多向上归位 3 px。日志持续追加、光标更新和代码高亮变化不重复触发入场。

收起不能靠复制日志或阻止宿主卸载来实现。首版优先做标题及箭头的短收束；只有确认宿主保留内容或提供关闭生命周期，才增加正文淡出。后续条目的平滑让位须先核对宿主已有布局动画和滚动锚定，不预先承诺高度动画；若会引起滚动跳动或大段重绘，直接保留原生收起。

原型中的完整展开、收起仅用于节奏评审。客户端能否覆盖相同的正文收起过程，取决于实际 DOM 生命周期。

## 并发、滚动与恢复

同一屏最多两张工具标题显示持续光绸，优先当前可见且最近进入运行状态的工具；其余保留原生运行提示。嵌套工具和过程分组不得同时叠加同一装饰。

隐藏窗口、离屏、折叠父分组时停止无效绘制或合成，返回后只续播仍在执行的工具，不重放开始和完成。历史已完成工具首次出现不补播完成动画。换会话、卸载、关闭效果时清理全部插件属性与装饰，宿主内容不经过透明状态。

## 设置与性能

在现有设置的「会话与页面」分组增加「工具执行动效」一个开关，统一控制工具出现、运行光绸、完成收束和可支持的展开反馈。首轮暂定默认开启，需用户确认视觉后再实施；不增设单独速度、亮度或高级参数。

优先使用局部 CSS transform / opacity，复用已安装的调度与暂停条件，不给工具新增 Canvas、WebGPU 设备或独立常驻 rAF。不为每条输出创建装饰。需要事件批处理时走共享机制；不逐帧读样式和布局，不扫描工具参数、终端输出或模型正文。四档性能偏好沿用，不虚构 CSS 动画受脚本帧率限制。

跟随系统减少动态：无平移、无流光、无呼吸、无收束动画，保留原生状态和展开结果。关闭效果时回到原生呈现。错误、取消和授权按钮始终可点，装饰不截获鼠标、键盘、选区或拖动。

## 首轮验收

先核对一张通用读取行和一张命令执行行，在客户端真实比例下确认光绸清晰但不抢正文。随后验证快速完成、连续展开收起、实时追加大量日志、并发、嵌套、切会话、加载历史、窗口恢复、减少动态和效果关闭。

只有同时满足不闪烁、不重复播放、不改变滚动位置与选择、不遮挡原生状态，并通过性能前后对比，才扩大覆盖到更多工具。

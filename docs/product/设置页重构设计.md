# 流光设置页重构设计

状态：2026-10-26，当前结构与轻反馈已随 1.0.0 发布。当前采用下述收敛结构，替代旧的四分区与锚点导航草案。范围为整个客户端的动效设置，不以对话场景或当前效果数量限定扩展方向。

## 目标

设置页应让用户依次回答：流光是否开启、整体呈现偏好是什么、哪些区域需要哪些效果。普通用户不需要先理解动画名称和实现参数；排查人员仍能找到真实状态。后续新增效果时进入对应区域，不继续增长为一个平铺开关列表。

## 当前问题

依据 `LuminaPanel.tsx`、`config.ts` 和实际效果安装关系核对：

- 品牌、强度、逐效果开关与发送状态混排，使用偏好与技术诊断层级相同。
- `sessionActivity` 同时控制运行星河、分组折叠和整体面板开合。用户关闭“会话进行中指示”会连带关闭布局动效，需要拆分。
- `press` 同时包含按钮反馈、发送反馈和菜单淡入。设置名称需准确描述覆盖范围；需要独立控制时再拆分。
- 预览只有迷你输入框和品牌条，无法解释发送模式、新会话编排与面板开合，不应宣称代表全部真实效果。
- 部分说明仍是早期实现，例如新会话淡入、spinner 呼吸；与当前行为不符。
- “强度影响所有效果”的说明不准确：当前部分效果使用固定时长和预算，不能用一段概括文案承诺全面控制。
- 既有工程设置页文档包含历史字段数量和原型示意，本稿作为后续重构的产品依据；真实存储模型以代码为准。

## 页面结构

保留宿主中的“流光”独立设置页。页内采用单页分区、紧凑锚点导航，不再增加一层侧栏或多层标签页。宽窗口可显示局部预览，窄窗口预览放在当前分区下面，避免横向挤压。

```text
流光                                     [启用]
让交互，泛起流光。
[整体风格] [全局交互] [区域效果] [排查与恢复]

整体风格
  品牌外观             DeepSeek / Ratel
  动效偏好             轻柔 / 标准 / 鲜明
  系统状态             跟随系统减少动态〔有条件显示〕

全局交互
  面板开合             左右侧栏与中间区域的衔接
  菜单与浮层           已接入的菜单进入、退出
  按压反馈             常用按钮的轻量反馈

区域效果
  导航与会话列表
    品牌标识
    运行状态流光
    分组展开与收起
  输入与消息
    输入框流光
    光标反馈
    文字出现反馈
    发送转场           关闭 / 水滴 / 消解 / 幽灵
  新会话
    入场动画           标识、标题、输入框及辅助控件的编排
  以后新增区域         按实际界面职责扩展

排查与恢复〔默认收起〕
  已安装插件版本
  发送转场状态与计数
  已验证的可用性信息

```

上述“菜单与浮层”只覆盖已验证接入的目标，不能暗示所有弹框都已支持。未实现的效果不放一个可操作的空开关；居中弹框等后续能力实现后再加入。

## 分区与控件规则

### 页首与整体风格

页首只保留名称、品牌文案与总开关。总开关关闭后保留全部选择，效果控制置灰并说明“启用流光后生效”；恢复默认与诊断仍可访问。由于采用草稿保存流程，总开关与其他设置同样保存后应用，不能视觉上暗示已立即改变客户端。

品牌外观与动效偏好分开：前者负责实际支持的标识、配色，后者负责节奏和视觉程度。重构时先核对每种效果对预设的支持，不写“改变全部效果颜色”或“统一调整所有时长”等无法兑现的说明。轻柔、标准、鲜明须有可见区别和已定义映射；尚未接入该偏好的效果保留固定设计，不另造无效档位。

性能优化由实现负责，同时提供综合档位适配不同设备。新增“性能”圆角分区，提供“性能优先 / 均衡 / 画质优先 / 极致画质”，默认“均衡”。四档使用单行分段按钮组，复用动效强度的共享选中样式（品牌色浅底、内描边、加粗文字），不另设白底阴影样式。不折成两行或改成下拉框，极窄窗口允许横向滚动。档位联合控制帧率、清晰度、粒子密度及光效精度等已接入参数，不再单独提供一级 FPS 选择。不保留独立的 `ⓘ` 或感叹号；悬停、聚焦档位按钮直接显示该档实际参数提示，点击选择档位；提示与渲染预算使用同一份配置来源。沿用草稿保存与热生效流程，不改变动画总时长，不暴露粒子数、DPR 等独立旋钮。参数映射、迁移和验收见[动效性能架构](../engineering/动效性能架构.md)。此项于 2026-10-26 接入，已验证草稿保存、取消、说明浮层和窄窗口布局，原生客户端仍需重启确认。

### 全局交互与区域效果

全局交互处理跨页面一致的动作；区域效果处理某处独有的呈现。例如整体面板开合属于全局，工作区分组折叠属于导航与列表。每种效果只出现一次，不在两个分区重复开关。

每行由短名称、一句范围说明、控制组成。开关适用于有无，互斥模式使用分段选择。发送转场直接显示模式，不再叠加一个含义重复的“启用发送”开关。只有存在可选参数的效果才展开详情；普通开关不需要进入二级页面。

新会话当前是一段整体编排，先保留一个开关，避免分别关闭标题、粒子、徽标造成顺序组合复杂。未来确有独立使用需求再拆分。

### 预览

预览跟随正在编辑的分区，默认为静态示意，用户点击“播放”才运行一次；持续效果仅在其预览可见时运行。不得在设置页同时常驻多个星河、粒子和发送演示。

优先复用真实效果绘制和时长来源。无法复用的示意要明确标注，不能把复杂装饰画当作客户端效果的承诺。预览使用假数据，不读取真实会话、不发送请求、不触发宿主面板状态。系统减少动态时不播放装饰运动，显示静态状态与简短说明。

预览基于草稿；真实客户端继续使用已保存配置。保存后当前客户端效果更新，无需重启；插件代码更新仍需完整重启。两者在页面文案中明确区分。

### 排查与恢复

发送状态和已启动次数移到默认收起的“排查与恢复”，不占区域效果的首行。计数只代表当前实现能够确认的范围；不得把它写成跨重启累计使用次数。版本来自构建信息，不硬编码。

未启用、系统减少动态、缺少接口、等待目标和运行异常必须区分；缺少诊断信号时显示“尚未确认”，不能仅凭开关开着显示“运行正常”。普通设置行只在确有阻断时显示简短原因，不展示所有内部状态名。

恢复默认只修改草稿，保存后应用；取消丢弃草稿更改。首版不扩展导入导出、配置云同步或快捷键。

## 保存与状态

沿用草稿、取消、一次保存的现有模型，避免本轮同时改变信息架构和持久化语义。页尾操作栏保持可达，只有存在差异时启用保存和取消；保存失败保留草稿并显示原因。分区切换不丢草稿。

保存后热生效。外部标签页更新设置时，无本地改动可同步；存在未保存改动时明确提示冲突，提供重新载入或继续编辑，不静默覆盖。离开页面时有未保存更改的提醒需先验证宿主导航能力；能力不足时不承诺全局拦截，至少在页内明确显示未保存状态。

系统减少动态是不可绕过的约束。开关保留用户偏好，实际运动暂停；不能把暂停误显示成用户主动关闭，也不新增忽略系统偏好的开关。

## 配置拆分与迁移

第一阶段至少把面板开合、分组折叠、运行状态流光从 `sessionActivity` 的连带控制中分开。名称应对应实际安装路径。按钮、菜单及发送反馈按实现边界拆分，避免只有界面开关独立、底层仍一起卸载。

旧配置迁移保留行为：旧 `sessionActivity=false` 的用户，原来受其控制的能力继续关闭；为 true 时继续启用。不要把新字段缺失直接视为开启而改变旧用户的关闭意图。保留现有发送模式和其他效果选择，重置才回到推荐默认。任何 schema 版本调整必须提供显式迁移，不能借版本变化整体丢弃旧配置。

## 实施顺序

1. **基础梳理**：建立“设置项—效果安装器—实际范围”映射；拆开连带开关并完成兼容迁移。
2. **结构重排**：实现上述四分区、准确中英文文案、草稿操作栏和折叠诊断；移除过时说明。结构与设置页自身动效分开验收，最新动效范围见文末。
3. **设置页自身动效**：按文末“空间层次＋局部光感”实现。效果演示暂缓，后续需要时另行确认。
4. **验收完善**：深浅色、窄窗口、键盘操作、减少动态、旧配置、保存失败、外部更新冲突及关闭后重新启用。

完成标准是用户能找到某个区域的效果、知道开关影响什么、分清草稿和真实状态；不是增加更多控件或更大的预览区。优先交付前两步，预览按复用程度逐项增加。

## 当前实施结构（替代前述导航草案）

页首保留总开关与整体动效偏好；主体依次为“界面与导航”“输入与消息”“新会话”；底部为默认折叠的“排查与恢复”。不增加锚点导航、搜索或独立大预览。品牌外观移至界面与导航。首轮优先实现结构与独立开关，旧的持续迷你预览移除，真实局部预览后续逐项接入，不展示无效预览按钮。仍采用草稿保存，并明确显示未保存状态。

## 视觉修订：页首总开关与圆角分块

按用户最新反馈，取消总开关独占分区，放入页首标题右侧；简介采用“让交互，泛起流光。”。二元选项使用滑动开关外观，保留键盘与辅助技术语义；品牌、强度、发送模式继续采用互斥分段选择。各分区使用主题语义背景的浅灰圆角块，不使用横向分割线。深色由语义 token 跟随。诊断维持折叠，保存区仍显示草稿状态。

### 分块底色对比度修正

用户在真实客户端未辨认出圆角底色。分区改用正文前景色与页面底色按 5%/95% 混合的自有 surface token，不再依赖背景层级之间的微弱差别；浅色为明确浅灰，深色自动形成略亮底板，不加硬分割线。

### 悬浮保存栏底部遮挡

保留悬浮保存栏。操作栏及其下方留白必须是不透明的完整底板，滚动内容不能从底部空隙露出；底色随主题变化，不影响按钮点击。

## 设置页自身的动效（2026-10-26）

本轮采用“空间层次＋局部光感”，作用于真实设置页；效果演示与局部预览暂缓，不属于本轮范围。

分区始终固定在原位，不做抬升或回落。获得焦点时以约 220 ms 的边缘与极淡底色渐变增加层次，弱化阴影，焦点离开后淡去。分区尺寸、文字排版和滚动位置不变。品牌、强度、性能和发送模式共用原有分段按钮组选中样式；用户选择不同选项时，在按钮内部播放一次约 420 ms 的宽幅柔光，不循环、不沿边追逐、不覆盖文字。保存成功后保存按钮给出相同的一次性确认，失败只保留草稿与错误提示。提示浮层以约 140 ms 的纯淡入出现，不做上下位移；在同一浮层中切换参数不反复重播。

光色跟随当前草稿品牌，未保存的更改不影响真实客户端。所有装饰点击穿透，焦点描边保持清晰；不开全屏光效、Canvas 或新的 rAF 循环。关闭总开关、减少动态、窗口隐藏或离开设置页时清理短反光。系统减少动态时保留静态焦点与选中识别，不抬升、不移动或闪光。宽窄窗口、键盘操作、快速连续选择与保存失败均须保持原操作语义。

## 1.0 独立短过渡开关

“界面与导航”加入弹框过渡、菜单与提示浮层、会话选中切换，独立于面板、分组和运行星河。新装默认开启；升级保留相关关闭意图，显式新开关优先。三项沿用草稿保存与热生效，不增加持续演示或新的二级导航。性能档位使用单行按钮组，参数直接来自预算表，不设独立感叹号。

## 1. 定位

> **Lumina 是 DSH 客户端的动效层：只改变「已有界面元素随时间如何变化」，外加一个封闭的品牌锚点。它不定义界面长什么样。**

三个关键词，缺一不可：

| 词 | 含义 | 反面 |
| --- | --- | --- |
| **动效层** | 只作用于时间维度（动画、过渡、缓动） | 不是皮肤、不是布局、不是组件库 |
| **封闭** | 用户只能从随包发布的集合里选 | 不能上传图片、不能调色、不能填毫秒数 |
| **品牌锚点** | 唯一豁免：一个品牌图形槽 + 由它派生的强调色 | 不是品牌定制工具 |

### 1.1 非目标（明确不做）

| 非目标 | 原因 |
| --- | --- |
| 主题系统（色板、字体、背景、圆角、间距） | 官方 `ui-theme` 已有扩展点（`ctx.theme.register` / `overrideTokens`），不占别人的通道 |
| 品牌定制工具（上传 logo、改字标文案、换徽标） | `dsh-brand-studio` 的职责 |
| 布局与信息密度调整 | 动效层不调布局，避免与官方改版冲突 |
| 自定义颜色 / 米级时长 / 贝塞尔曲线参数 | 用户把设计调坏的成本远高于收益 |
| WebGL / 粒子背景 | 高频交互区引入 GPU 上下文，代价大于收益 |
| 修改 `app.asar` | 破代码签名，macOS 拒绝启动 |
| 监听模型输出内容做动效 | 越界，且触碰业务逻辑 |

## 2. 边界判据（准入五问）

任何新需求逐条过，**任一为否即出局**：

1. **它是否只改变时间维度的呈现？**（品牌锚点是唯一豁免）
2. **用户是否只能从我们随包发布的封闭集合里选？** —— 不能输入任意值
3. **关掉后界面是否完全回到官方样子？** —— 无残留、无空壳、无占位
4. **是否不改变布局与信息密度？**
5. **是否不承载信息？** —— 关掉不丢语义

> 第 2 条是最强的过滤器。它一句话挡掉「能上传我自己的 logo 吗」「能调成绿色吗」「能慢一点吗」这三类最常见的越界请求。

### 2.1 代码级约束（可审查）

边界要能在代码里查，不能只是口号：

| # | 约束 | 检查方式 |
| --- | --- | --- |
| C1 | 消费 `var(--dsw-alias-*)`，**不写死主题色** | 全库检索字面量颜色 |
| C2 | **永不调用** `ctx.theme.register` / `ctx.theme.overrideTokens` | 检索 API 名 |
| C3 | `--lumina-*` 只发布在 `[data-lumina]` 作用域，不挂 `:root` | 检索 `:root` |
| C4 | 品牌图形只来自包内 `assets/`，无上传、无外链 | 检索 `http` / `<input type=file>` |
| C5 | 所有效果不写业务状态；除发送转场外只读 `data-*` 与 `--dsw-*`。发送转场仅在用户提交手势期间临时读取当前草稿的可见文字和排版，通过公开只读提交快照关联 requestId，再读取对应用户消息排版；不读助手正文、不持久化文字 | 人工审查 |
| C6 | 一个开关 / 一个 data 属性 / 一次卸载，都能回到官方样子 | 验收项 |

## 3. 与相邻产品的关系

| 产品 | 拥有 | 我们的关系 |
| --- | --- | --- |
| `@deepseek-ai/dsh-client-ui-theme`（官方） | 全部 `--dsw-alias-*` token、深浅色 | **只消费，不注册** |
| `dsh-brand-studio`（社区） | 自定义 logo / 字标 / 徽标 / 页面标题 | **让位**（见 3.1） |
| `@deepseek-ai/dsh-client-ui-brand-official`（官方） | 官方品牌占位者（仅 `official` 构建启用） | 我们以更低 priority 覆盖 |
| **Lumina** | 时间维度行为 + 已发布品牌预设 | 独立 |

### 3.1 特异性排序（取代"抢 slot"的对抗）

```
用户自定义资产（brand-studio 上传的 logo）      ← 更具体，Lumina 让位
        ↑
Lumina 内置品牌预设（deepseek / ratel）         ← 默认
        ↑
官方默认品牌
```

**规则：更具体的赢。Lumina 永不提供"更具体"的手段（上传），所以让位规则没有歧义。**

实现：读取 `localStorage["dsh-brand-studio/settings/v1"]`，若 `logo !== null` 则不注册品牌 slot，并在设置页显示「品牌由 dsh-brand-studio 管理」。

### 5.1.1 输入框边缘光晕（M2）

**意图**

输入框是用户停留最久的焦点。它应该“活着”，但不能像加载动画一样持续抢注意力。
视觉目标是宣传海报里的那层光：**冷蓝为底、少量暖珊瑚、边缘透明、柔软、有空气感**；
不是一圈实心描边，也不是常驻旋转的 loading 环。

**两个状态**

| 状态 | 视觉 | 运动 | 触发 |
| --- | --- | --- | --- |
| **平时** | 2–3px 渐变亮边（蓝 → 暖珊瑚 → 蓝），边缘外有一圈半透明蓝色光晕；卡片原有的实心边框隐藏 | 光晕由内向外缓慢呼吸，亮边**不旋转**；聚焦时呼吸节奏略缓 | 输入框存在即生效 |
| **发送 / 流式** | 亮边收束为一道蓝色光弧，其余边缘只留很淡的蓝；光弧沿卡片边缘行走 | 仅此时旋转，一周约 **2.4s**（normal）；流式结束立即回到平时呼吸 | 仅在发送后 `[data-lumina-streaming]` 存在时 |

**视觉规则**

- 蓝色取客户端官方 accent（浅色约 `#4176e6`），暖色取当前品牌预设的浅色；
- 蓝色是输入框的主色，不直接使用 logo 的红色——红留给品牌和发送闪光，避免两个焦点抢；
- 光晕必须**透明、可呼吸**：靠渐变、半透明和外层柔光形成，不靠加粗实线；
- 卡片原实心边框在效果启用时置为透明，关闭后恢复；不允许出现“黑边压蓝边”；
- 不改输入框尺寸、圆角、背景、文字、选区和点击区域；装饰层 `pointer-events: none`。

**强度**

| 档位 | 平时呼吸周期 | 发送光弧一周 |
| --- | --- | --- |
| subtle | 4.8s | 3.6s |
| normal | 3.6s | 2.4s |
| vivid | 2.8s | 1.68s |

**降级与边界**

- 不支持 `mask-composite` → 不注入光晕，绝不盖住输入内容；
- 不支持 `@property` → 保留静态渐变柔光，不旋转发送光弧；
- 取不到输入框卡片 → 无效果，不影响输入；
- 减少动态 → 光晕静止，发送时也不旋转；
- 只作用于输入框卡片本身；海报中卡片外的流动光带属于宣传画面，不在运行时复刻。

**验收**

| # | 验收点 |
| --- | --- |
| 1 | 平时亮边+光晕可见，且连续采样 3 次光晕/透明度不同，证明在呼吸 |
| 2 | 平时没有旋转：没有持续变化的 `--lumina-angle` 或旋转 transform |
| 3 | 发送后光弧出现并旋转；流式结束后回到平时呼吸 |
| 4 | 开启/关闭效果时，输入框 `getBoundingClientRect()` 不变，无布局跳动 |
| 5 | 浅色/深色主题下都是蓝色光，不出现黑边；卡片实心边框只在关闭时可见 |
| 6 | 减少动态下光晕静止，发送不旋转 |
| 7 | 覆盖层不拦截点击、输入、拖拽和选区 |

### 6.3 设置页结构与状态

```
┌ Lumina · 动效 ────────────────────────┐
│ 一句话说明                              │
├ ⚠ 状态横幅（条件）─────────────────────┤  ← 减少动态 / 品牌已让位
│ 启用动效                       [●——]  │
├ 品牌预设 ────────────────────────────┤
│  DeepSeek(红) | Ratel(蓝·待发布)       │  ← 不可用项禁用 + 说明
├ 动效强度 ────────────────────────────┤
│  柔和 | 标准 | 鲜明                    │
├ 预览 ────────────────────────────────┤
│  [品牌条 + 流光]                       │
├ 诊断（折叠）─────────────────────────┤
│  ▸ 钩子检查 · v0.1.0 · 复制诊断信息    │
├──────────────────────────────────────┤
│ [恢复默认]              [取消] [保存]  │
└──────────────────────────────────────┘
```

**必须支持的 5 个状态**：

| 状态 | 表现 |
| --- | --- |
| 正常 | 全部可操作 |
| 系统要求减少动态 | 横幅说明 + 开关置灰（**不隐藏**），且不提供关闭该跟随的选项 |
| 品牌已让位给 brand-studio | 品牌区只读 + 说明 + 指向对方 |
| 钩子未命中 | 诊断区标红，横幅提示「部分效果可能不生效」 |
| 有未保存修改 | 保存/取消可用 |

## 7. 品牌预设规格

### 7.1 预设 = 包内资产（一等发布物）

```
预设 := { 图形资产 + 动效机制参数 + 强调色 + 徽标策略 }
```

- 预设随包发版，**不提供用户组合能力**
- 新增预设 = 一次发版，不是运行时配置
- 图形基线已定：**沿用 v2 资产**（476×98），保证迁移零视觉变化；不跟随客户端官方字标改版

### 7.2 `deepseek` 预设（V1 唯一可用）

| 项 | 规格 | 来源 |
| --- | --- | --- |
| 画布 | 476×98 | `assets/deepseek-harness-logo-v2.svg` |
| 鲸鱼 | 纯色 `#FF3B30` | 同上 |
| 字标 | 渐变 `#12100F → #8C1D12 → #FF5C48 →` 回溯 | 同上 |
| 流光 | mask + 光带，3.6s，`cubic-bezier(.45,0,.55,1)`，`translateX(-100px→392px)` | 同上 |
| 徽标 | HARNESS 深底白字，深色模式反转 | 同上 |
| 渲染尺寸 | 侧栏 24px / Hero 34px | 本节 |

**必须改造的两处（合规）**：

1. 边缘色 `var(--dsh-edge, #12100F)` → `var(--dsw-alias-label-primary)`
2. 删除 `@media (prefers-color-scheme: dark)`，改由 token 自动跟随

### 7.3 `ratel` 预设（后续阶段，资产待设计）

- 状态：**不可选**，面板显示「待发布」
- 原因：蜜獾图形尚无资产（风险 R15）
- 不做占位色块上线——不发半成品

### 7.4 实现陷阱（必须处理）

**SVG `id` 必须按实例去重。** 同一资产会同时挂三处（侧栏 mark、侧栏 name、hero mark），直接内联会让 `url(#dshWordMask)` 全部指向第一个实例。必须用 React `useId()` 给 `id` 加前缀。

## 8. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 依赖 | 运行时零第三方依赖；仅 `require` 模块表 specifier |
| 性能 | 只动 `transform` / `opacity`；常驻动画 ≤2 条；不引入长任务 |
| 无障碍 | 跟随系统「减少动态」，**不提供关闭入口**；动效不承载信息；对比度 ≥4.5:1 |
| 降级 | 钩子/资产缺失时静默降级，且设置页如实说明 |
| 可卸载 | 卸载后无 `.lumina-*` / `[data-lumina*]` / `<style data-plugin>` 残留 |
| 兼容 | 客户端升级后靠 `data-*` 与官方 slot 存活；不依赖 hash 类名 |

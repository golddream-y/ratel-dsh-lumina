# 输入与新会话动效需求

> 本文的新会话编排已随 0.3.0 发布。页面丝带、水纹和水滴细化也已发布，见[丝带流光与液态发送](丝带流光与液态发送需求.md)；当前交付与待办见[功能实现状态](功能实现状态.md)。


状态：2026-10-23 最新确认需求，客户端实现与受控验证完成；真实 DSH 重启后的观感待核对。本文描述当前目标；旧 A＋C 上浮、柔光与固定外光方案已废弃，历史决策保留在工程记录中。

## 目标

新会话先建立输入框和品牌标题，辅助控件最后进入。装饰不改变消息、文案、焦点、选区或下拉框功能；开启系统减少动态时，全部内容直接显示。

## 新会话时序（正常档）

| 阶段 | 时间 | 画面与范围 |
| --- | --- | --- |
| 输入框聚合 | 0–1100ms | 整个输入框的边框、可见文字、图标和按钮底板由附近散开的细粒子聚合，末段交回真实控件 |
| 品牌描边填色 | 0–1800ms | 小鲸鱼与“探索未至之境”标题先绘制轮廓，再填充；原位绘制，不上浮、不回弹 |
| 辅助控件 Echo 入场 | 前两项实际结束后，约 1800–2300ms | “手册”工作区下拉框、“创造模式”预设下拉框、“预览版”徽标，以及同一新会话选项行内的辅助控件最后出现；从右侧进入，两层淡残影向左收敛成一个清晰控件 |
| 静止 | 全部结束后 | 移除装饰层与等待状态，恢复原样；不持续循环、不做悬停爆散 |

鲸鱼与标题描边从上一版 1500ms 再放慢至 1800ms。粒子聚合保持 1100ms，不因描边放慢而延长。Echo 参考 React Bits Echo Text 的残影归位，不是整块输入框的错位复制。所有辅助项等待主动画全部完成，再一起开始，不能提前常亮或在聚合阶段闪现。

### 三档时长

| 项目 | 轻柔 | 正常 | 鲜明 |
| --- | --- | --- | --- |
| 输入框粒子聚合 | 1250ms | 1100ms | 950ms |
| 鲸鱼和标题描边填色 | 2000ms | 1800ms | 1600ms |
| Echo 入场 | 560ms | 480ms | 420ms |

Echo 不延迟可用性：用户在当前输入框或辅助控件上点击、按键或编辑时，立即结束等待和残影，交还全部真实控件。输入框内部滚动、尺寸变化、会话 key 变化、关闭效果和卸载也必须还原。自动聚焦、同一会话的重复通知、无关区域的按键及页面随布局滚动不取消入场；局部装饰随宿主移动。已有非空草稿不粒子化。

## 文字输入与回复

新字使用清晰彩色字形副本和短余辉，正常档约 450ms，同批 35ms 错峰；只点亮新增部分，删除不点亮。支持中间插入与替换、完整 emoji 字素、中文组合输入提交后播放；每批最多 8 个、同时最多 24 层。光层不进入编辑器，不改变原文、布局或选区。输入与回复使用主题变量区分色调，回复只读取现有 streaming 语义区域的 DOM 增量。

## 接入与性能边界

- 所有颜色和时长来自主题与 Lumina token；自写原生 Canvas、SVG、CSS，不增加动效运行时依赖。
- Canvas 挂在真实输入框内部，随宿主移动；最多 2400 个粒子，按颜色分组批量绘制，DPR 最高 1.5、物理像素最多 200 万。结束停止 rAF，不能永久漂浮。
- 品牌槽实际有 display:contents 的 `data-slot="conversation.hero.brand.mark"` 包装，预览必须保留。标题按槽锚点和已验证结构定位，不用 hash 类名或匹配翻译文本。
- 辅助控件以 workspace、agentPreset、options 的语义槽和标题旁徽标定位；保留原始控件与事件，只加自有、无交互的文字残影。
- 系统减少动态不能被页面选项覆盖。卸载后 Canvas、SVG、残影、等待标记、计时器和监听全部清理。

## 参考与验收

视觉参考：[Particle Text](https://reactbits.dev/text-animations/particle-text)、[Stroke Text](https://reactbits.dev/text-animations/stroke-text)、[Echo Text](https://reactbits.dev/text-animations/echo-text)。只参考效果说明与视觉，自写实现。

当前预览为 `docs/demo/particle-stroke.html`，通过 `node tools/serve-motion.mjs` 启动，加载实际 `lib/client.js`。验收要覆盖：真实槽包装、描边变化与结束、粒子收敛、辅助项在主动画结束前不可见/结束后 Echo 归位、交互打断、尺寸变化、系统减少动态、窄屏与卸载清理。受控浏览器证据不替代真实 DSH 客户端重启后的视觉、IME 和帧率核对。

### 客户端触发修正

用户反馈真实 DSH 动画整体消失。检查并复现自动聚焦和会话快照重复通知造成的提前清理：自动 focusin 不等于主动操作，同一会话 key 的服务通知不等于切换会话。仅在 key 实际变化时清理；交互取消限定为当前入场目标上的主动指针、键盘或编辑事件，不用全页面 focusin 作为取消条件。受控宿主新增自动聚焦、重复通知、真正切换会话与输入打断回归场景。

### 辅助项延迟挂载与进入方向

用户反馈“创造模式”默认就显示、没有参加 Echo。辅助槽可能在品牌组件提交后才挂载或替换内容，不能只在开始时取一次按钮列表。等待阶段在当前新会话的辅助语义槽外设置门控，晚挂载内容也不可提前显示；在主动画完成前持续收集目标，开始 Echo 时再核对一次。取消、减少动态和卸载清理门控与观察器。

最后一波统一从右向左进入：真实控件从右侧约14px归位，淡文字残影从右侧10px/20px收敛，末尾无位移。描边1800ms、粒子1100ms和完成屏障不变。

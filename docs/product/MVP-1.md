## 2. 动效改编清单

改编依据是**依赖**：零依赖的可改编代码，带 `motion` / `gsap` 的只取思路、用平台原语重写。

| 我们的效果 | 上游组件 | 上游依赖 | 取什么 | 丢什么 | 改编量 | 需登记 |
| --- | --- | --- | --- | --- | --- | --- |
| M1 品牌字标流光 | **ShinyText** | 无 | 光带渐变停靠点的生成（带宽 × 柔度 → 多 stop）、多光带、`glow` 模糊副层 | `background-clip: text`（SVG 无此属性）、rAF 逐帧驱动 DOM、React 组件壳 | 中 | ✅ |
| M2 边框流光 | **BorderGlow** | 无 | `mask-composite` 挖空、多层渐变堆叠、光晕柔化 | 指针驱动（`--edge-proximity` / `--cursor-angle`）——我们是被动环绕 | 小～中 | ✅ |
| M3 打字机光标 | TextType | `gsap` | 光标呼吸的 CSS 曲线 | GSAP 状态机、打字逻辑 | 极小 | ❌ 只需抄几行 CSS |
| M4 按压 + 闪光 | Magnet | 无 | 弹簧刚度/阻尼比，用作 `cubic-bezier` 调参依据 | 指针磁吸、物理循环 | 小 | ❌ 只调参 |
| M5 首屏入场 | BlurText | `motion` | 模糊→清晰的 keyframe 结构与错落延迟 | `motion/react` | 中 | ❌ 纯 CSS 重写 |

**明确不采用**：`ClickSpark`、`ElectricBorder`、`StarBorder`、`SpecularButton`、`SwarmCursor` ——
Canvas / WebGL 路线，与"只动 transform/opacity、零运行时依赖"冲突。

## 3. 改编期同样适用的硬约束

改编**不豁免**任何产品边界与工程约束：

1. **零运行时依赖**——不得引入 `motion` / `gsap` / `three`；上游组件依赖它们时，只取思路重写
2. **只 `require` 模块表内的 specifier**——其余必须打进 bundle；引入大库会让包体从 12KB 涨到数百 KB
3. **保留原始版权头与许可声明**，不删不改
4. **每完成一个改编就立刻登记** `THIRD_PARTY_NOTICES.md`，不留到最后
5. 改编后的实现仍须满足：只改时间维度、封闭集合、可完全关闭、不承载信息

---

## 4. 实施顺序

顺序由依赖决定，不按效果编号：

1. **适配层 L1** —— 架构设计 §13 指出的缺失项。五个效果都要靠它，先做能省四次返工
2. **品牌动效** —— 资产已完备（`assets/deepseek-harness-logo-v2.svg`），零依赖，最稳的起点
3. **边框流光** ← BorderGlow 的遮罩叠层
4. **打字机光标** ← TextType 的 CSS 曲线
5. **按压 + 闪光** ← Magnet 的弹簧参数
6. **首屏入场** ← BlurText 的 keyframe 结构
7. **设置页 + 诊断** —— 收口

每一步都必须留下可执行证据（见 §6），不允许"代码看起来对"。

## 6. 验收

沿用 [产品需求 §10](产品需求.md) 的 A1–A9，并为每个效果补各自的可测项：

| 效果 | 追加验收 |
| --- | --- |
| 品牌 | 连续采样 `.lumina-shine` 的位置互不相同；减少动态时 `animation-name: none` |
| 边框流光 | 点输入框四角与中心都能聚焦（`pointer-events: none` 生效）；聚焦后时长变短 |
| 光标 | 位置与宽度零变化；选区高亮仍可见 |
| 按压 | 禁用态无反馈；连续发送 3 次闪光不叠加 |
| 首屏 | 会话间切换不误触发 |

# Ratel Lumina · 流光

[English](README.md) · 中文 · [npm](https://www.npmjs.com/package/@ratel-works/dsh-lumina) · [更新记录](CHANGELOG.md)

**让输入、发送与回复之间的衔接更自然。**

Ratel Lumina 是 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 的动效增强插件。从输入框聚焦时的柔光，到文字化为水滴、消解或小幽灵的发送转场，再到回复过程中的光标反馈，让日常对话有连续、可感知的交互反馈。

适用于 DSH 的桌面端与 Web / PWA 客户端。动效可以按偏好调整，也可以随时关闭。

## 为什么用 Lumina

- **连贯的交互反馈**：输入框、发送按钮、消息转场与回复光标使用一致的光感和节奏，让动作之间的衔接更清楚。
- **可以选择的表达**：发送可以化为水滴、文字消解或小幽灵；也可以关闭转场，只保留轻量反馈。
- **按自己的节奏使用**：提供动效强度、配色预设和效果开关，保存后即时生效。
- **保留原有工作方式**：不修改模型、请求或消息内容，不延迟真实发送，装饰层不阻挡输入、点击与选中。
- **轻量且可退出**：使用 CSS 和原生 SVG，不额外引入动效框架；支持总开关，跟随系统「减少动态效果」。

## 动效体验

| 场景 | 表现 |
| --- | --- |
| 准备输入 | 混色边框常驻，聚焦后出现柔光与流动光带 |
| 点击发送 | 按压反馈与短促的光感确认 |
| 发送消息 | 水滴、文字消解、小幽灵转场，或关闭 |
| 等待回复 | 流式光标反馈与会话进行中指示 |
| 打开新对话 | 品牌与首屏入场动效 |

### 选择发送方式

**水滴**是默认模式。整段文字收拢成水滴，融入输入框边缘，再剥离、飞向消息位置并展开。

**文字消解**让文字逐字散开，在消息位置由模糊逐渐变得清晰。

**小幽灵**用圆润、头身一体的幽灵带走文字，披风下摆随风翻卷，抵达后消息整段淡入。

已有的有效模式选择会保留，更新插件不会强制重置。

## 安装与更新

先安装 DeepSeek Harness，然后把插件加入实际使用的 profile：

```sh
dsh plugin --profile <profile> add @ratel-works/dsh-lumina
```

将 `<profile>` 替换为所用 profile，例如 `desktop` 或 `web`。升级时重新运行这条命令，然后**完整退出并重新打开客户端**，加载新的插件代码。

当前开发与验证基线为 DSH `0.2.1-rc.2`。客户端升级后，动效依赖的界面接口可能变化，需重新验证兼容性。

## 设置

打开 DSH 设置中的 **Lumina / 流光** 页面，选择发送方式、动效强度与配色，或关闭不需要的效果。调整后保存即可生效，无需重启。

想恢复原有界面时，关闭 Lumina 总开关即可。系统启用「减少动态效果」时，插件会自动减少或停用动画。

设置保存即时生效；安装、升级插件代码则需要完整重启客户端。

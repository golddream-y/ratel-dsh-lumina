# 设置热生效与代码需重启

日期：2026-10-22。用户发现切换发送转场模式后**不用重启**就看到了效果。

## 机制

客户端把设置存在 store 里，设置页保存走 `store.commit`；客户端在安装时订阅
`store.subscribe(render)`，任何设置变化都会 `disposeEffects()` 后用新配置重新
`installEffects()`。因此模式切换、开关、强度、品牌预设都是**当场生效**的。

而 `src/` 里的代码改动只影响**下次启动**加载的 client bundle：重新构建并安装只是更新了
profile 里的文件，当前页面仍在跑旧 bundle，必须完整退出客户端再打开。

## 结论

- 此前"完全看不到效果"的现场问题属于**代码类**，需要重启才能验证；
- 排查时先分清"设置类"还是"代码类"：设置类直接改设置当场验证，代码类先重启再看；
- 模式切换能热生效，这让"水滴 / 消解 / 雾气"三者在现场对比变得很快。

# 隔离水滴文字表现并设为默认

用户反馈水滴像混入文字消解，要求水滴成为默认。排查确认模式分派只安装一个渲染器；混淆来自 liquid 自身的逐字旋转、错峰收拢和逐字展开变色。改为整段文字层几何收拢与展开，字形内部排版不变、无文字模糊或逐字消散，保留水体局部融合滤镜和完整液面阶段。

默认与缺失/无效模式回退至 liquid，有效已存选择及旧布尔迁移不覆盖。

## Alternatives considered

- 卸载 dissolve 模式：没有双模式同时运行的证据，删除其它模式不能解决 liquid 内部表现混淆。
- 只移除模糊：liquid 文字原本没有 blur；需要移除逐字错峰、旋转和颜色交接。
- 强制覆盖所有用户已存设置：默认变更不应重置用户明确选择。

## 验证

类型检查、49 项测试、构建通过。新增两项水滴专项覆盖 240 字整段收拢、落地展开的排版关系与无文字模糊。tools/verify-liquid.mjs 以无已存模式配置的生产 bundle 采样 17 帧，默认 liquid；源与目标字形相对排版固定，只有整层变换；存在液面连接，卸载后叠层/遮罩/样式均为 0，无页面错误。证据：本次会话可视化目录 liquid-only/evidence.json。受控页面验证不等同于真实客户端验收，需完整重启客户端加载代码。

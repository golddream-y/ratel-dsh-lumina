# 幽灵透明度、风感路径与"为什么像消解"

日期：2026-10-22。客户端反馈：幽灵透明度不够；路径还是一条弧线，没有被风吹乱的感；并且幽灵带着消解的落地特效。

## 为什么像消解（架构问题）

幽灵渲染器在落地时**整段复用了消解的代码**：整层 blur 解析 + 逐字 opacity 渐入 + 逐字错峰。两个模式本来应该有不同的交接方式，却因为代码复制变得一样。

修复：把交接抽成 `transfer/reveal.ts` 的两种显式风格：

- `revealBlur`：整层从模糊解析（消解用，React Bits Blur Text）；
- `revealFade`：整层直接淡入，无模糊、无逐字渐入（幽灵用）。

现在"幽灵像消解"不再是观感问题，而是两个模式各自选择了不同的函数。

## 透明度

幽灵填充的三段 stop 从 `.95 / .82 / .62` 降到 `.8 / .62 / .4`，描边透明度 `.5 → .32`，整体再乘 0.9 的入场透明度；拖尾雾 0.24。它现在是"半透明的红"，不是实心贴纸。

## 风感路径

原来是从起点到终点的一条二次贝塞尔（一条干净弧线）。现在改成 `gust()`：

```text
位置 = 直线插值 + 法向 × (sin(2.6π·fly + φ)·10 + sin(4.7π·fly + 1.7φ)·5) + cos(1.9π·fly + 0.8φ)·5
```

两段不同频率的横向波叠加 + 一个慢上下浮，路径因此是**不规则的游走**而不是一条弧；再按路径切线给幽灵一个 ±14° 的倾斜，看起来是被风推着走。拖尾雾沿同一条路线滞后 0.15 跟随。

源端文字也改成"被吸向幽灵"（向释放点收缩 + 淡出，不再逐字模糊），避免和消解的源端散开混淆。

# 气泡先出现与小幽灵形态

日期：2026-10-22。用户在客户端反馈两点：发送时对话气泡先出现再开始动画；小幽灵的形象不对，应该是一团雾气飘过去。

## 气泡

之前遮罩的是**文字元素最近的带背景祖先**。气泡的背景与文字不在同一层时，遮罩只隐藏了文字，气泡背景留在对话列表里，于是读起来像"气泡先出现，然后动画才把它盖住"。

改为遮罩**整条消息行**：从文字元素向上找 `[data-submission-echo]` / `[data-chat-node-key]` / `[data-chat-flow-key]`，找到即遮罩整行（背景 + 文字一起消失）；找不到才退回带背景祖先。行在转场开始时就被隐藏，因此顺序变为"气泡消失 → 汇聚 → 转场"。

## 形态

用户否掉了圆润小幽灵，改为"一团雾气飘过去"。`ghost` 模式重写为 `mist`：五个径向渐变光斑组成一团雾，整体 blur(5px)，沿弧线飘行并轻微旋转，到达后散开淡出，文字在雾散时解析成形。光斑自身的漂移交给 CSS keyframes（`lumina-mist-drift`），每帧只更新整体 transform，比逐帧算光斑便宜。

模式 id 随形态一起改名：`ghost` → `mist`，设置项显示为「雾气」。旧设置里没有该模式，只有布尔开关迁移，因此没有中间态需要处理。

## 验证

类型检查、构建、40 项单元测试通过；原型页 `docs/demo/mist.html`。真实客户端需完整退出重启后确认：气泡在动画开始前消失、雾气形态与飘行节奏可接受。

## 边界

雾气为红色半透明（用户指定）。气泡行遮罩是整行隐藏，若宿主把行做成可交互元素（按钮、菜单），隐藏会一并隐藏交互，落地时由真实文字接管。

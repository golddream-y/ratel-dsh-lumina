# 新会话页面丝带流光

用户确认按宣传图左下丝带构图落地，并明确允许跨侧栏，只需不妨碍点击。本轮仅实现流光，发送波纹和水滴新材质仍待实现。

## 实现

composerGlow 管理一个局部绘制的视口 Canvas，7 层连续透明带面、双侧亮边与平滑低频形变；从页面左下汇入输入框外缘，向右淡出。输入框内以偶奇裁切保持透明。默认不绘制，聚焦且主入场结束后 450ms 淡入，失焦淡出。沿用原有细边与开关，不新增持久化字段。

语义定位集中在 adapter/targets.ts，使用官方 hero seat、composer card 及布局框架。Canvas 无事件处理、pointer-events none。绘制循环不读布局，无滤镜，约 30ms 绘制一次，DPR 上限 1.25、像素上限 250 万；未聚焦、隐藏、减少动态及离场停止/清理。布局数据由观察器、resize 与滚动事件更新。

## Alternatives considered

- 将当前星河提亮：无法提供连续带面和厚度，拒绝。
- 多层 CSS blur 或大范围 SVG 滤镜：叠层和模糊成本高，未采用。
- 仅裁切在主内容区：用户明确允许越过侧栏，改为视口绘制。
- 单独高保真 Demo：容易再次与客户端脱节，原型直接加载实际 bundle。

## 验证

类型检查、构建与 74 项测试通过。受控浏览器 1440×1000、1024×700：idle opacity 0，focus opacity 1，两次 Canvas 数据不同；侧栏区域 elementFromPoint 命中原界面而非 Canvas；输入框中心 RGBA [0,0,0,0]；blur opacity 0，无横向溢出；减少动态及 hero 移除后 Canvas 数量 0；pageerror 为空。已查看实际构建截图。

原生客户端未做视觉与帧率验收，不承诺固定帧率或与静态宣传图逐像素一致。desktop/web 安装后需用户完整重启。

## 实机截图反馈后的形态重做

首版平行色带和沿上边框的折转不符合宣传图。改为一条舒展的连续三次曲线，向输入框左侧汇入；五层低透明底光、九层薄膜、二十四根细高光随共享流场交错。去除卡片顶部横带及右侧延伸。

验证：typecheck/build 与 74 项测试通过；实际 bundle 浏览器采样 moving=true、clickThrough=true、inside alpha=0、idle/blur opacity=0、reduced/exit canvas count=0、errors=[]。1440×1000 与 1024×700 截图无水平溢出。尚未验证原生客户端视觉与帧率，不能称为宣传图完全复刻。

### Alternatives considered（本轮）

仅提高旧条带亮度会保留塑料条与直角问题，故重做曲线与层次；不采用逐帧全画布 blur，以避免增加大面积滤镜成本。

## 贯穿构图重设计

用户认为延伸比例失衡，改用输入框为尺度基准的下缘 S 曲线：左侧约 0.6 倍框宽、右侧约 0.18 倍框宽，端部渐隐；窄屏按框宽收敛厚度与起伏。取消左下向上爬升的巨大斜带。需求已同步。

实际 bundle 验证：moving=true、clickThrough=true、输入框内部 alpha=0、失焦 opacity=0、减少动态与离场 canvas 数量=0，无页面错误与水平溢出。检查宽屏截图后适度增强局部起伏与薄层厚度。最终 typecheck/build/74 项测试通过。原生客户端视觉待重启确认。

Alternatives considered：以窗口宽度延伸会放大宽屏中的装饰比例；直接压低旧斜带高度仍保留单侧截断，因此改为框下贯穿、两端收束的构图。

## 先材质、后构图

按用户指令保留路径和延伸比例。移除九层薄膜加二十四根光丝的线束，改为三张随时间扭转的曲面，按横截面分带着色，具有透明边缘、彩色透光、偏心白色反射和单条折边。截面分带增加细度并微量重叠以减少抗锯齿接缝；不使用全画布 blur。

实际构建验证 moving=true、clickThrough=true、inside alpha=0、blur=0、reduced/exit=0、errors=[]；宽窄截图无溢出。typecheck/build/74 项测试通过。客户端真实帧率未测，视觉还原尚未获用户认可。

Alternatives considered：继续叠加细线不能形成宽面，故减少独立曲面数量并增加截面光照；保持现有构图遵从用户先质感后位置的顺序。

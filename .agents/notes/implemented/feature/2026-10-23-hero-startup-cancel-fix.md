# 修正新会话启动即取消动画

用户确认真实 DSH 客户端动画消失。上一轮 Echo 接入把全页面 focusin 和 uiSession.current 的每次通知都连到 clear，局部粒子还监听全页面 scroll。宿主自动聚焦和同 key 服务通知可在入场初期清除 Canvas、标题与 Echo。

受控复现：聚焦前 canvas/title/waiting=1/1/3，程序化 focus 后变0/0/0；重复通知前1/1/3，通知后0/0/0。修正后两种情况均保持1/1/3，并继续完整描边、聚合与 Echo。

## Alternatives considered

- 延迟启动掩盖聚焦：不能覆盖同 key 后续通知，改为准确判定取消条件。
- 禁止客户端自动聚焦：会改变输入行为，未采用。
- 删除所有取消：会影响实际输入和卸载还原，保留当前入场目标内的指针、按键与编辑取消。
- 让任何滚动都取消：局部装饰天然跟随宿主，改为只在目标内部滚动取消，页面布局滚动继续。

## 实现与验证

订阅比较 key，只有真正变化才清理；取消 focusin 监听；文档事件按当前标识、卡片和辅助项的包含关系过滤。新增回归覆盖程序化聚焦、同 key 通知、无关区域按键、页面滚动、真正输入及切换会话。

类型检查、构建与71项测试通过。实际 bundle 受控宿主在模拟自动聚焦、通知和页面滚动后完整播放主动画及 Echo；交互打断、减少动态、窄屏与卸载清理通过，无页面错误。证据为本会话可视化目录 hero-startup-fix/evidence.json 等；复现前后结构计数保存在 /tmp/lumina-cancel-before.json 和 /tmp/lumina-cancel-after.json。此证据未直接操作真实 DSH；真实客户端需重启后核对。

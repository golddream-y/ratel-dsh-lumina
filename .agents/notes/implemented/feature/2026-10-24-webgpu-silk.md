# 新会话丝带 WebGPU 内核

用户明确指定直接采用 WebGPU。原生 WebGPU/WGSL 替换 Canvas 2D 绘制，现有位置、设置归属和显隐语义不变。旧 painter 保留历史对照，运行 bundle 不调用。

三张参数曲面通过 vertex_index 生成，128×6 网格，共 4608 三角形，三次 draw、一次 pass/submit。共享对齐 uniform buffer；连续参数法线与片元材质避免 CPU 分带着色。4× MSAA 在尺寸变化时重建，预乘透明与解析圆角输入框遮罩。DPR 最高 1.25、150 万物理像素，纵向 scissor 限制片元范围。资源在 dispose、初始化失败、设备丢失与异步卸载竞态中清理；失败停用装饰，不修改宿主 flags。

静态样板 `docs/demo/silk-material.html` 共用 renderer，默认固定时间，支持滑块与播放并遵从减少动态。用户尚未认可视觉还原；真实 DSH GPU 可用性和性能未测。

## 验证

- typecheck/build/74 项测试通过。
- Chrome 默认 GPU 配置：secure/gpu/adapter=true，实际 webgpu context 出图成功。
- 时间 uniform 多点采样 1.3665→1.3832→1.3999→1.4166，证明更新；不等同于 FPS 性能测量。
- 点击穿透=true，失焦 opacity=0，减少动态/离场 canvas 数量=0。
- device lost 后 canvas=0；延迟 adapter 200ms 后卸载，destroyed=1、writes=0、canvas=0。
- 无 GPU API 时 canvas=0，editor focused=true；生命周期与静态样板 pageerror/警告=[]。
- 宽窄窗口与两个固定时间材质截图已检查，仍需原生与用户视觉验收。

## Alternatives considered

早期建议 WebGL 2，用户明确改选 WebGPU，因此不维护双后端。Canvas 多条带叠加多次未满足材质目标，改用参数曲面与连续着色。初始未启用 MSAA 时边缘有锯齿，采用有界多采样纹理并释放。暂不启用 bloom，避免以全屏模糊掩盖曲面问题。

## 材质反馈迭代

根据用户对锯齿、光感与柔顺度的反馈，固定构图，增加导数抗锯齿覆盖、局部白亮折面与低密度解析柔光；弯曲、宽度、扭转使用不同低频相位。当前三主体加三柔光共 6144 三角形、六次 draw、1536 字节 uniform buffer，仍单 pass 与 4× MSAA，无全屏模糊。技术设计同步修订，不再使用早期三次提交的预算描述。

本轮 typecheck/build/74 项测试通过，实际 WebGPU 材质截图已检查；连续 uniform 采样变化、设备丢失、延迟初始化卸载、无 GPU 时编辑器可用均再次通过，无页面错误。原生帧率与用户视觉认可仍未取得。

## 同向薄片形态重做

用户否定上一版形态，重做三曲面的局部开幅、交错路径与非线性扭转；红色与蓝色各有主导曲面，高光集中在折面和单侧薄边。添加低强度连续褶皱明暗，减少等色面。保持整体位置与横向范围，资源预算不变。

两个固定时间样板截图已检查，开幅与交叉关系可辨；构建与 74 项测试通过，实际 WebGPU 脚本复验多时刻 uniform 变化、device lost、延迟初始化卸载及无 GPU 保留编辑能力，errors=[]。客户端已安装，视觉还原仍未通过用户验收。

Alternatives considered：继续调亮相同平行曲面会保留塑料薄片感，故直接改形态；未加更多独立细线或全屏 bloom。

## 白底亮芯与彩光

用户再次指出看不到光。保持几何与位置，改为高对比近白亮芯、较强近场红蓝透色、低透明远场光晕，避免仅提高白色或整面泛白。解析衰减与调色由既有 palette 派生，不增加 pass / draw。不是 HDR bloom，不能宣称物理光照。

typecheck/build/74 项测试与实际 GPU 生命周期脚本通过；白底样板截图已检查，可见亮芯周围色彩对比增加。README 光感还原仍未通过用户验收。

Alternatives considered：单纯提高白色在白底上不能形成对比，故提高近场彩光与亮芯的层次；尚未加入全屏后处理，保持当前性能范围。

## SVG 轮廓驱动（先设计、后实现）

按用户要求，先在专项技术设计中确定 SVG 为几何唯一来源，再实现 assets/motion/silk-ribbon.svg 六条手工 Bézier 边界、构建采样工具及 WebGPU 只读 storage buffer。三张带面在公共 x 位置反求参数并采样，每张 129 对边界，共 6192 字节。生成工具只支持 M/C 并拒绝非单调曲线、缺失路径和不收束端点；源 SVG 的填面由同一工具生成。build/build:client 集成生成步骤，--check 防止源与数据不同步。运行时不用 SVG 解析或纹理截图，既有位置不变；基准帧复现边界，运动仅作有界偏移与深度变化。

验证：typecheck/build/76 项测试通过，包括新增管线同步与不支持命令拒绝。浏览器原生 SVG getPointAtLength 独立核对 198 个采样位置，最大误差 0.0020046 个 SVG 单位。实际 WebGPU 样板与客户端 fixture 出图正常，时间更新、device lost、异步卸载及无 GPU 编辑器保留通过，errors=[]。迟到初始化发生一次静态 storage 上传、没有绘制，device 销毁一次。两时刻截图已检查，用户美术验收尚未通过；不将轮廓误差等同于视觉还原度。

Alternatives considered：SVG 转静态纹理会让主要高光随贴图运动，SVG 与 GPU 分层则易错位。采用边界采样驱动同一曲面，高光保持实时计算。暂不引入细节纹理或外部运行时。

## 细化 SVG 外观保真首版交付

用户要求实现一个版本。为保住已认可美术，当前运行时改为 SVG 视觉资产纹理加 WebGPU 128×8 细分网格，旧参数曲面 renderer 移入 composer-ribbon-surface-renderer.ts 保留实验对照，不被客户端调用。主要高光、褶皱和聚光来自包内 SVG，不能宣称实时三维光照或翻面；连续小幅网格形变同步带动所有细节，位置与范围保持。

构建脚本内联美术源，首次初始化栅格化为 2048×608 透明纹理并上传一次。帧内仅更新 32 字节 uniform，一次 draw / submit、2048 三角形、4× MSAA。释放纹理、MSAA、buffer、device 及 Blob URL；离场、隐藏、减少动态主动释放 renderer。新增生成同步测试，typecheck/build/77 项测试通过。

实际浏览器确认：SVG 细节与局部暖光保留，两个时间点截图已检查；连续 uniform 更新，device lost 后 canvas=0；延迟初始化卸载 destroyed=1、writes=0；无 GPU 时 canvas=0、编辑器仍可聚焦。聚焦 opacity=1、失焦=0、点击穿透=true、减少动态与离场 canvas=0，宽窄窗口出图正常。生命周期脚本 errors=[]；集成脚本仅有 favicon 404，无 shader 或页面运行异常。已安装 desktop/web，未重启客户端，原生视觉与性能仍待确认。

Alternatives considered：直接重新计算材质会丢失细化 SVG 的局部光晕和褶皱，用户此前反复否定该结果。首版选择纹理保真加网格形变，接受主要高光随资产运动的限制；不叠两套运动装饰，不引入第三方运行时。

## 新会话原生窗口拖拽兼容

用户进一步澄清并非按钮点击失败，而是新会话窗口不能拖动，已有会话可拖，点空白后光带可消失。此前点击穿透检查不足以证明原生拖拽安全。针对全窗口装饰层这一风险，改用实际光带包围范围的 canvas / MSAA 缓冲，顶部至少保留 64 CSS px 无装饰画布；世界坐标通过 crop uniform 投影，位置和形态不变。只给装饰自身 no-drag、draggable=false、pointer-events:none!important，不改宿主窗口拖拽区域。

实际 fixture：activeBounds x=110 y=583 width=1176 height=362，425712 物理像素，pointerEvents=none、appRegion=no-drag，标题栏完全在画布外。真实测试按钮点击回调执行1次；blur opacity=0、离场canvas=0、重入canvas=1、窄屏top=483/bottom=700、减少动态canvas=0、pageerrors=[]。typecheck/build/80 项测试通过。原生 Electron 窗口拖拽未直接验证，尚不能宣称根因和修复结果已在原生确认。

Alternatives considered：仅 pointer-events:none 不能验证 Electron 原生 app-region 行为；不使用全窗口 no-drag 或修改宿主 CSS，因为会直接破坏业务窗口的拖拽定义。采用装饰局部化并保留标题栏。

## 构图、首播流入与持续传输

用户反馈上一版平铺、流动不明显，要求从一端流向另一端再持续流动。重定位左段为抬升曲线，中段收束并短暂藏入下缘，右尾缩短；原稿材质保留。片元按 u 软前沿在约1.65秒展开，之后以同向的两组明暗包络沿带面输运，伴随有界形变。首次同会话失焦不重播，场景/会话标识变化才重置。集中 token 管理时长与速度，无新增纹理读取或 draw。

实际 GPU 样本：0.4/1.0/1.8秒下缘区域最右可见x=381/846/1127；3.2和5.6秒有14635个像素变化超过5/255，证明展开与持续变化。失焦续播时钟1.583→2.133，新会话重置后0.067；按钮点击执行1次，blur=0，exit=0，reenter=1，reduced=0，pageerrors=[]，标题栏在画布外。typecheck/build/80项测试通过。实际原生构图与流动观感仍待重启确认。Demo新增重播流入按钮，只改受控fixture会话标识。

Alternatives considered：只增大上下起伏不能表达沿线传输；不滚动整张纹理，以免已认可褶皱和首尾连接断裂。不使用单点来回扫光或全带统一呼吸。

## 框边穿插与分层舒展

沿用单纹理、单 draw call。在左右框边分别收束并进入卡片遮罩，右侧加宽横截面；SVG 中增加独立珊瑚薄片与不等长冷色细丝。两处转折按世界坐标提供局部提亮，横截面微动错相。没有新增宿主 DOM 覆盖层，也没有改变标题栏排除范围。

### Alternatives considered

不复制整幅光带制造层次，避免重复图样及额外采样；不添加覆盖编辑区的前景画布，保留原生输入、按钮与拖窗边界。主高光仍来自手绘资产，GPU 局部提亮不是物理光照。

实际 bundle 的 Chrome WebGPU 验证：流入 0/0.4/1/1.8/3.2/5.6 秒截图；失焦再聚焦时间继续，新会话时间重置至 0.067 秒。局部画布 1363×579，顶部 421 px；点击回调 1，移出会话/减少动态后 canvas 为 0，控制台无错误。客户端最终观感待用户重启确认。

## 曲率与高光精度

放宽左右收束的过渡区并降低下压幅度，横截面微动减半。白色调制上限从 0.72 降至 0.32，转折亮芯收窄，SVG 暖光斑缩小以保留透色。网格 256×16，纹理 3072×912，画布 DPR 上限 2、240 万像素预算；保持单 draw、单次纹理上传及 4×MSAA。普通分辨率实际 WebGPU 无报错，流入与会话重置正常，80 项测试通过。

### Alternatives considered

不靠全局模糊抹掉折线，也不整体降低透明度解决泛白。提高精度会增加显存和填充开销；保留像素预算，不声称帧率没有变化。构图与画布拖窗保护保持原样，最终原生客户端细节需重启查看。

## 设置独立控制

原丝带随 composerGlow 安装，hero 开关仅管理首屏入场，导致用户对设置含义产生混淆。新增 composerRibbon 默认开启，缺失时继承旧 composerGlow；拆开两个安装器与 registry gates。在新会话分组加入丝带开关，说明保存与聚焦触发时机，入场说明注明进入新会话后播放。

### Alternatives considered

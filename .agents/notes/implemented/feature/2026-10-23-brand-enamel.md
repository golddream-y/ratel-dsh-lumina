# 鲸鱼质感预设

保留原始路径，以线性渐变和径向柔光实现审核图的材质方向。设置提供实际组件预览，保留 ratel/deepseek 存储标识。沿用描边入场及减少动态，无新增持续动画。

## Alternatives considered

AI 位图轮廓有偏差，不便描边入场；SVG 滤镜增加绘制成本，因此采用渐变路径叠层。

## 周期喷水补充

用户指定随字标流光定期播放。共用 brand-sweep 变量，标准档 9 秒；70% 之后轻浮、喷水、回落。仅侧栏周期播放，设置预览及 hero 不增加循环。CSS transform/opacity，无新增计时器；焦点/回复期间跟随字标暂停。

实际构建 slot 检查：字标 9s、鲸鱼 9000ms；72% 到 84% 采样 transform 从轻微旋转变为 -3deg/-1px，水柱 opacity 从 0 变为 .9；减少动态水层 display none。类型检查、构建、74 项测试通过。

新会话补充：Echo 自然完成回调触发单次 1400ms 喷水，取消不触发；水层默认透明，循环样式仅作用于侧栏 periodic 类。实际 bundle 的 hero slot 每 300ms 采样：前七次 opacity 0 / animation count 0，随后 .012/.438/.9，最终恢复 0 / count 0；periodic 始终 false，pageerror 为空。74 项测试通过，已重装 desktop/web。

## 短水柱迭代

小图标水弧难辨，替换为有实体宽度、顶部略展开的短水柱和亮芯，去掉零散水珠及鲸鱼旋转。水柱高低起伏两次，身体同步上下微动。保持两种触发及减少动态规则。实际 bundle 周期采样 opacity 0→1，新会话采样 0→1→0 且动画数最终回到 0，无 pageerror；类型检查、构建、74 项测试通过。

## 水感细化

实体直柱替换为曲线路径裁切与透明渐变，局部亮纹向上流动；水柱轻弯、粗细变化，末段两滴水向侧下方落下。描边入场仅作用于鲸鱼主体 path，避免水柱裁切路径误参与入场。CSS/WAAPI 均有取消及减少动态分支，无新增滤镜。构建、类型检查及 74 项测试通过；实际 bundle 周期 opacity 0→1，单次播放最终 opacity 0 / 动画数 0，pageerror 为空。小尺寸最终水感仍需用户在原生客户端验收。

# A＋C 输入与新会话动效落地

用户确认独立原型后明确要求修改客户端。本次将选定节奏接入插件，不改客户端包、请求或输入焦点。

输入新字为清晰字素副本加短余辉，正常档 450ms、35ms 错峰；中文组合输入在提交后播放，中间插入/替换按共同前后缀识别，删除不点亮，完整 emoji 字素不会拆开。每批 8、存活 24 上限；样式时长来自统一 token，卸载、滚动和尺寸变化清理光层、待处理帧和计时器。回复仅使用 data-streaming 语义区域内的 DOM 文字增量。

新会话通过只读 uiSession.current 订阅身份，组件提交后认领播放记录，避免 React 渲染重试消耗机会。每会话首次进入播放，返回不重播。标识 360ms 入场，局部光 60–660ms，输入框独立装饰层 180–700ms。保留静态混色边框以及既有聚焦效果。

## Alternatives considered

- 继续模糊文字：看不清字形，改成清晰彩色核心加 text-shadow。
- 仅比较字符数量：中间插入/替换和 emoji 定位错误，改为字素差分、UTF-16 DOM Range。
- 渲染时写已播放集合：StrictMode 与重渲染会提前消耗，移到提交阶段。
- 整屏光幕：范围太大，改为标识附近的局部渐变；输入框响应使用自有层，避免争用边框伪元素。
- 用业务输出服务驱动逐字效果：装饰不应绑定模型内容，保留语义 DOM 增量边界。

## 验证及限制

类型检查、构建、63 项测试通过。实际 lib/client.js 在受控浏览器中多点采样：标识从 matrix(.95,0,0,.95,0,8) 变为单位矩阵；局部光透明度 0→约 .896→0；输入框响应 0→约 .659→移除。新字 filter=none，随后全部清理。系统减少动态下 animation-name=none，光层隐藏；卸载后样式、装饰与订阅均为 0，无页面错误。

证据位于会话可视化目录 client-compose/evidence.json、entrance.png、input.png。此为实际构建受控宿主证据，不能替代真实 DSH 界面与真实 IME 验收。桌面和 Web 配置安装后需用户完整重启客户端加载。

# 整体面板与中间区域协同

## 决策

用户反馈左右整体开合与中间区域脱节，先更新需求后获实现授权。只读已安装 AppFrame 源码验证三列 grid、data-rightbar-col 及 collapsed/dragging/fullscreen/instant 钩子。单个三列网格的像素列宽从当前值过渡到宿主最终值，保留正文自然排版，不缩放文本、不改业务 store。关闭原网格 transition 避免叠加，以本地时长 token 协调原生后代。开合以外的拖动、窗口大小变化、instant/fullscreen、减少动态取消动画。

## Alternatives considered

- 仅给左右面板加 transform：中间区仍会跳位，未选。
- 把中间内容截图平移或缩放：文字失真且输入不可交互，未选。
- 修改宿主布局 store 或 app.asar：违反插件边界，未选。
- 依赖原 data-animating 与 grid 的 CSS transition：无法保证变更前状态已建立，也受列模板结构影响，改用已计算像素列宽。

## 验证

实际 bundle 受控三列宿主：初始240/560/300；左收中途129.875/670.109/300；反向前后中间左边界88.375/88.375，无起点重播；恢复240/560/300。右收中途240/749.25/110.734，结束240/860/0。减少动态及拖动均 animations=0，无页面错误。两次以上布局采样证明中间区域和边界变化。浏览器 fixture 截图位于 /private/tmp/lumina-panel-fixture.png，不代替真实 DSH 验收。右侧 occupant 自有滑出节奏仍需实际客户端对照，未声称全客户端像素一致。

## 性能优先替换

用户反馈严重掉帧并要求不用测，原三列逐帧动画取消。一次最终布局加 translate 衔接，避免长文持续重排；原侧栏零宽退出用原列临时绝对定位，清理还原，不复制交互节点。观察范围缩到框架，星河共享短时绘制预算。取舍：接受文字换行在开始时一次完成，优先降低布局开销。类型检查和构建通过；按用户要求未运行帧率、浏览器采样或额外测试，不沿用上文旧版数字声称新版性能。

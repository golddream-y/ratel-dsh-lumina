# 水滴材质与剥离近景样板

## Decision

先交付 docs/demo/liquid-study.html 审阅稿；用户随后要求接入，现已安装 desktop 与 web 本地 profile。样板复用正式 createLiquidRenderer 与阶段函数，支持0.55倍慢放、正常速度、暂停、拖动时间和深浅底；水体近景1.8倍。基础半径由14调为16，正式阶段时间与整段文字规则保留。

移除 alpha 阈值滤镜，水滴和液桥由同一连续外轮廓绘制，保留透明径向层次；液面用连续三次曲线，增加薄边、短高光及少量暖反射。CSS 从发送入口提取到轻量 styles 模块，供样板直接使用；原有入口继续导出 transferCss、MASK 保持兼容。

## Alternatives considered

不靠加大 blur 或 alpha 阈值融合，它们会冲掉透明层次；不采集背景做真实折射。先审阅近景再接入原生客户端，避免仅凭单帧或测试通过宣称质感已获认可。外观为矢量绘制近似，尚未做真实液体模拟。

## Evidence

类型检查、构建及91项测试通过。浏览器直接调用共享renderer，160/390/580/680/820/1010ms分别呈现汇聚、融合、隆起、剥离、飞行及展开，深浅底均已截图检查，pageerrors=[]。浅底轮廓较深底轻，最终质感待用户判断；本地 bundle 已替换但包版本暂保持0.6.2，未发布。预览服务只在127.0.0.1提供src/client范围内的开发期TS转译，不进入发布包。


## Client integration

第二稿增加倾斜牵引、收颈、断开回缩和飞行拉伸，并增强白底局部明暗。正式 renderer 默认1倍，预览1.8倍。正式 bundle 17帧验证通过，整段文字、减少动态及卸载清理正常，errors=[]。desktop/web 的已安装 client.js 与工程构建 SHA-256 一致，bundle 注册项存在；等待用户完整退出重启后的原生视觉确认。

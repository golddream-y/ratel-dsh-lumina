# 新会话最后显示辅助控件，使用 Echo 入场

用户要求先维护最新需求，再调整：上方描边再慢一点，手册、创造模式下拉框和预览版等辅助项都使用 Echo Text 方向，等其他动效完成后才出现。

先重写 docs/product/输入与新会话动效设计.md 为当前需求，旧 A＋C 留在工程历史，不再与当前方案并列。描边正常1800ms，轻柔2000ms、鲜明1600ms；粒子聚合时长不变。辅助项通过真实语义槽定位，useLayoutEffect 中先准备等待状态。完成屏障同时等待鲸鱼、标题和粒子结束，再播放480ms的两层文字残影归位，保留真实按钮、原事件与功能。交互、减少动态、尺寸变化、滚动、会话变化和卸载均立即还原。

## Alternatives considered

- 只给 Echo 写固定延迟：时长改变或渲染迟到容易提前露出，改为三阶段实际完成屏障与有界超时兜底。
- 复制整个下拉框：会复制交互节点和标识；只加局部装饰文本副本。
- 主动画开始时让辅助项常亮：不符合最后出现要求，使用不改变布局的等待透明度。
- 同时延长粒子：影响控件交接且用户只要求上方更慢，粒子保持现有节奏和预算。
- 原样引入 React Bits Echo Text：仅参考公开视觉说明，用本地 CSS/DOM 实现，不新增依赖。

## 证据

类型检查、构建与70项测试通过。实际bundle在保留SlotOutlet的受控宿主中验证：早期与粒子完成后，3项均waiting、opacity=0；鲸鱼与标题animationend后才转playing，两次采样transform不同，至少6层残影；结束后标记、残影归零。点击中断立即显示原控件，系统减少动态直接显示；390px无横向溢出，卸载后Canvas、标题、Echo与样式全清零，无页面错误。

证据目录为本会话可视化目录 hero-echo/evidence.json、early.png、echo.png、settled.png、mobile.png。真实 DSH 重启后的观感仍需核对，受控预览不替代客户端验收。
